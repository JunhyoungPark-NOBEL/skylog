# 역사 천체물리 학습 흐름 · 2026-09-11

## 학습 순서

10개 역사 이야기를 각각 **9개의 연속 단계**로 표시한다. 기존 30개 채점 문항과 60개 관측 질문을 같은 카드 안에서 이어 가며, 사용자에게 준비/본문제 경계를 표시하지 않는다. 30개 장 제목과 60개 연결 문장을 `historyStory.ts`에서 한국어·영어로 제공한다. 관측 질문의 별도 연습·구슬 비유도 같은 천문학 이야기의 질문으로 옮겼다. 기존 수치·선택지·정답 ID는 유지한다.

- 한 번에 한 장면과 질문을 표시한다. 오답이면 이유를 확인하고 다시 고른다.
- 정답 확인 뒤 같은 `다음으로` 버튼으로 진행한다. 3→4, 6→7은 다음 장면으로 연결하고 4→3, 7→6도 같은 이전 버튼으로 돌아간다.
- `이야기 순서`에서 장을, `단계 이동`에서 해당 장의 단계를 고를 수 있다. 이동만으로 정답이나 완료를 기록하지 않는다.
- 저장된 관측 질문의 응답을 읽어 아직 풀지 않은 단계에서 재개한다. 기존 풀이·입력·메모가 있으면 해당 계산·추론 단계로 연다.
- 이전 단계를 복습해도 같은 장의 작성 중인 답과 메모 컴포넌트를 유지한다. 장 경계를 넘을 때는 이야기 안의 문항 ID·풀이 라운드별 초안을 보관하여 6→5→4→3처럼 이동했다 돌아와도 입력이 남는다. 기기에 영구 보관하려면 기존 저장 버튼을 사용한다. 이미 풀었던 관측 단계를 다시 맞히지 않고 이어 갈 수 있다.
- 그림에 있는 수치의 적용 단계를 명시하여 앞의 비율 질문과 혼동하지 않게 한다. 계산·추론 단계에서도 그림·관계식·풀이의 연결 고리를 펼칠 수 있다.
- 마지막 단계의 풀이 확인 뒤 이야기 목록으로 돌아가 실제 채점 문항의 해결 수를 확인한다.

## 용어와 수식

현재 문제의 용어와 별칭을 긴 항목부터 찾는다. 점선 밑줄이 있는 용어를 **450ms 길게 눌러야** 설명이 열린다. 짧은 터치·클릭은 열지 않으며 키보드 Enter·Space는 유지한다. 9px 초과 이동, 포인터 취소·이탈, 스크롤, 창·용어의 포커스 이탈은 진행 중인 홀드를 취소한다. 오른쪽 마우스 버튼·보조 포인터는 열지 않는다. 선택지 내부에는 중첩 버튼을 만들지 않는다. 열린 설명은 원래 손가락/마우스를 떼어도 유지되며, Escape·닫기 버튼·새 배경 제스처로 닫고 원래 용어로 초점을 돌린다.

수식은 명시적으로 구분한 LaTex만 KaTeX로 조판한다. 자연어의 영문 한 글자를 임의로 변수로 판단하지 않는다. 변수는 수학 이탤릭체, 아래첨자는 전부 직립체다. HTML+MathML을 함께 제공하고 외부 CDN 없이 CSS·글꼴을 앱에 묶는다. 긴 수식만 가로 스크롤되며 화면 전체 폭을 밀지 않는다. 라이브러리의 신뢰 옵션을 끄고 임의 HTML을 받지 않는다.

## 저장과 이용 권한

`progress` 테이블의 `learn.preparation:<questionId>` 키에 버전과 실제 응답 ID들을 저장한다. 본 문제의 `learn.history:` 키·라운드·정답·힌트·메모를 변경하지 않는다. 가져온 완료 플래그는 믿지 않고 실제 선택지와 정답으로 다시 판정한다. 올바른 응답 이력은 복습 중 오답을 골라도 남는다. 트랜잭션으로 동시에 열린 화면의 응답을 합친다. 유료 권한 확인은 DB 트랜잭션 시작 전에 수행한다.

현재 공개 모드는 기존과 같은 Plus 베타 미리보기다. 이 작업은 구매 서버·실결제·상품 활성화를 수행하지 않는다.

## 검증 범위

단위 검증은 30개 장면 연결, 응답·권한·정답 보존, 수식 파싱과 아래첨자, 홀드와 스크롤 구분, 원래 풀이 초안 보존, 도해의 기하·좌표를 다룬다. 브라우저 검증은 1→9 전체 진행과 장 경계를 넘는 되짚기, 짧은 탭 무동작, 실제 터치·마우스 홀드, 360px·영어·125% 글자·야간 모드·진도 재진입을 확인한다. 실제 서비스워커를 이용하는 오프라인 회귀는 별도로 수행한다. 실행 결과와 배포 증거는 `plan/STATUS.md`와 해당 빌드 보고서에 기록한다. 브라우저의 터치 모사는 실제 휴대전화 검증과 구분한다.
