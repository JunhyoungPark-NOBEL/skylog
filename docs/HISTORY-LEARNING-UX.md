# 역사 천체물리 학습 흐름 · 2026-09-11

## 학습 순서

기존 10개 역사 이야기와 본 문제 30개의 앞에 두 선행 문제를 둔다. 첫 문제에서는 관측 상황·개념을, 두 번째에서는 계산에 필요한 비율·수학·물리 관계를 연습한다. 용어 정의를 길게 읽어야 다음으로 넘어가는 구성은 사용하지 않는다.

- 한 번에 준비 문제 하나를 표시한다. 오답이면 이유를 확인하고 다시 고른다.
- 정답을 맞힌 뒤 다음 준비 문제, 이어 본 문제로 이동한다.
- 본 문제로 바로 이동할 수 있다. 이 동작을 준비 완료로 기록하지 않는다.
- 기존 풀이·입력·메모가 있으면 본 문제부터 이어서 연다.
- 준비 문제를 다시 열어도 작성 중인 본 문제 입력과 메모를 언마운트하지 않는다.
- 그림·관계식·풀이의 연결 고리는 본 문제에서도 펼쳐 볼 수 있다.

## 용어와 수식

현재 문제의 용어와 별칭을 긴 항목부터 찾는다. 점선 밑줄이 있는 용어를 450ms 누르거나 탭·Enter·Space로 선택하면 설명이 열린다. 9px를 넘는 이동과 포인터 취소는 홀딩 및 뒤따르는 클릭을 취소한다. 선택지 내부에는 중첩 버튼을 만들지 않는다. 설명은 Escape·닫기 버튼·배경으로 닫고 원래 용어로 초점을 돌린다.

수식은 명시적으로 구분한 LaTex만 KaTeX로 조판한다. 자연어의 영문 한 글자를 임의로 변수로 판단하지 않는다. 변수는 수학 이탤릭체, 아래첨자는 전부 직립체다. HTML+MathML을 함께 제공하고 외부 CDN 없이 CSS·글꼴을 앱에 묶는다. 긴 수식만 가로 스크롤되며 화면 전체 폭을 밀지 않는다. 라이브러리의 신뢰 옵션을 끄고 임의 HTML을 받지 않는다.

## 저장과 이용 권한

`progress` 테이블의 `learn.preparation:<questionId>` 키에 버전과 실제 응답 ID들을 저장한다. 본 문제의 `learn.history:` 키·라운드·정답·힌트·메모를 변경하지 않는다. 가져온 완료 플래그는 믿지 않고 실제 선택지와 정답으로 다시 판정한다. 올바른 응답 이력은 복습 중 오답을 골라도 남는다. 트랜잭션으로 동시에 열린 화면의 응답을 합친다. 유료 권한 확인은 DB 트랜잭션 시작 전에 수행한다.

현재 공개 모드는 기존과 같은 Plus 베타 미리보기다. 이 작업은 구매 서버·실결제·상품 활성화를 수행하지 않는다.

## 검증 범위

단위 검증은 선행 문항의 참조·저장·권한, 수식 파싱과 아래첨자, 용어 입력과 스크롤 구분, 원래 풀이 초안 보존, 도해의 기하·좌표를 다룬다. 브라우저 검증은 좁은 화면·영어·확대 글자·야간 모드·진도 재진입·사진 출처를 확인한다. 실행 결과와 배포 증거는 `plan/STATUS.md`와 해당 빌드 보고서에 별도로 기록한다. 브라우저의 터치 모사는 실제 휴대전화 검증과 구분한다.
