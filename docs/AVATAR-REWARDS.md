# 아바타 보상과 기존 코디 보존

2026-09-11 · beta.15 준비

아바타 편집 방식과 기존 그림체는 유지한다. 새 사용자는 두 옷 색(세이지·테라코타), 관측 점퍼, 비니 또는 모자 없이 시작한다. 피부·머리 모양·머리 색·표정은 모두 기본 제공한다. 나머지는 관측과 퀴즈의 성취로 모으도록 아바타 보상을 12개에서 **28개**로 늘렸다. 꾸미기 보상을 별도 판매하거나 확률로 지급하지 않는다.

## 기존 사용자와 표시 범위

- `LEGACY_FREE_AVATAR_OPTIONS`는 build19까지 기본 제공했던 선택 목록이다. 기존 프로필이나 보관 코디가 있는 사용자의 이관에만 사용하고, 새 사용자의 기본 목록으로 사용하지 않는다.
- 현재 입은 옷과 보관한 코디, 이전에 기본 제공했던 8개 옵션을 잠그지 않는다. 원래 업적 보상이던 12개와 이번 신규 8개는 이관 목록에 넣지 않는다.
- 기존 보상 키·아바타 필드 이름은 유지한다. 서버 공개 프로필의 허용 목록에는 새 선택값 8개를 추가한다. 공개 아바타를 보는 것만으로 로컬 보상은 해제되지 않는다.
- 사진·댓글의 원형 초상은 아바타만 표시한다. 배경 선택은 아바타 편집 미리보기에 유지하고, 지평선 배치와 아바타를 함께 보여 주는 프로필 화면은 별도로 구성한다.

## 그림과 검증

`AvatarArt.tsx`에서 기존 선 굵기·색 팔레트·둥근 실루엣을 사용한 독자적인 정적 SVG를 그린다. 원격 이미지·스크립트·서드파티 도안을 추가하지 않는다. 초승달 배지, 토성 고리, 천문관 돔, 코트의 작은 망원경 문양, 별을 잇는 판초, 두 갈래 혜성 머플러, 별자리판, 태양계 모형은 작은 크기에서도 형태로 구분한다. 실제 관측 자료로 사용하는 도해는 아니며 축척을 나타내지 않는다.

- 단위 검사: 28개 보상 잠금·소유·기본값, 이전 무료 선택의 정확한 범위, 기존 프로필 정규화, 8개 그림의 구분, 한영 이름·획득 조건, 댓글 배경 제거.
- 시각 검사: `artifacts/qa-build20/avatar-gallery.tsx`로 실제 컴포넌트를 렌더링했다. 98개 모자·머리 또는 의상·소품 조합의 SVG 경계 초과 0건, JavaScript 오류 0건이다.
- `avatar-rewards-gallery.png`·`avatar-rewards-mobile.png`·`avatar-rewards-night.png`를 직접 확인했다. 360px 폭의 3열/80px 미리보기, 38px 원형 초상, 적색 야간 필터를 포함한다. 독립 렌더링 검사이며 실제 휴대폰 화면 확인과 구분한다.
- 통합 보상 이관·공개 프로필·지평선 검사와 최종 빌드 결과는 `plan/STATUS.md`에 기록한다.
