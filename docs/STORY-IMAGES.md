## 사진 선택과 출처

`getObjectPhoto`의 정확한 ObjectId 일치를 우선한다. 별 사진은 시리우스와 베텔게우스다. 별자리나 사진 없는 별에 비슷하게 보이는 다른 천체 사진을 넣지 않는다.

예외는 NGC 869와 NGC 884 두 이야기다. 기존 `dso:C14` 사진은 이 두 성단을 **함께** 담은 2MASS 관측 모자이크이며, 사진 메타데이터와 원문으로 대상 범위가 확인되어 있다. 목록에는 ‘이중성단 사진’, 상세에는 두 성단을 함께 담았다는 안내를 표시하고 C14 사진의 원문 설명·출처를 유지한다. 일반적인 NGC 번호/별칭 추정으로 사진을 대체하지 않는다. NGC 457·NGC 7009는 정확한 사진이 없어 위치 도해를 쓴다.

사진은 기존 `PhotoThumbnail`과 `ObjectPhotoCard`를 재사용한다. 기존 권리 조건·크레딧·가시광/근적외선 등 파장 설명·가공 내역은 변경하지 않는다. 목록과 오늘 카드에는 출처를 길게 나열하지 않으며, 상세에서 이미지 바로 아래 전체 크레딧·출처·라이선스·권리 근거를 제공한다. 개별 사진의 권리는 [OBJECT-PHOTOS.md](OBJECT-PHOTOS.md)를 따른다.

## 도해의 의미와 데이터

도해는 실제 관측 사진이 아니다. 기존 카탈로그의 J2000 적도 좌표를 북쪽 위·동쪽 왼쪽의 입체투영으로 표시한다. RA 0°/360° 경계와 천구 극에서 경도가 벌어지는 왜곡을 피하기 위해 구면 벡터를 사용한다.

- 별자리: 연결선의 별 위치 평균 방향을 중심으로, 해당 별자리의 모든 연결선이 들어오는 범위를 선택한다. 연결선은 별자리 모양을 알아보기 위한 것으로 물리적 구조나 별자리 경계를 뜻하지 않는다.
- 사진 없는 별·DSO: 실제 대상 좌표를 도해 중심에 표시하고 주변 지름 30°의 별을 그린다. 표시는 실제 천체 크기나 망원경상 크기를 뜻하지 않는다.
- 주변 별은 카탈로그에서 밝은 순 최대 90개를 그린다. 선 끝점이 밝은 별 목록에 없더라도 원래 선 카탈로그의 좌표를 사용해 연결 구조를 보존한다. 작은 화면의 별 점은 읽을 수 있는 최소 크기를 적용한다.
- 별자리 연결선은 d3-celestial / Olaf Frohn의 BSD-3-Clause 자료, 별 위치는 HYG / David Nash, DSO 위치는 OpenNGC / Mattia Verga의 CC BY-SA 4.0 자료다. 좌표를 SVG 도해로 재구성했음을 상세에서 밝히며 해당 출처·라이선스 링크를 제공한다. HYG/OpenNGC를 포함한 도해는 CC BY-SA 4.0으로 제공한다. 기존 배포 데이터 팩의 고지·라이선스는 유지한다. 원본 기록은 [DATA-LICENSES.md](DATA-LICENSES.md)를 따른다.

도해는 관측 시각·관측지의 실시간 하늘 방향을 보여 주는 화면이 아니며, 실제 하늘에서 돌아가 보일 수 있음을 설명한다. 태양의 안전 안내는 큰 이미지보다 먼저 나온다.

## 로딩·접근성과 검증

카탈로그는 기존 `loadCatalog`의 공유 캐시를 쓴다. 목록에서는 이미 학습 상태가 가진 카탈로그를 전달한다. 도해는 화면 근처에 왔을 때 계산하며 카탈로그·ObjectId별 결과를 목록/상세에서 재사용한다. 사진 썸네일의 지연 로딩과 사진 오류 시 기본 아이콘/상세 재시도 기능은 기존 동작을 유지한다. 읽음 체크 배지와 읽음 텍스트도 유지한다.

야간 사진은 기존 적색 보호 필터를 사용한다. 원래 색 보기의 명시적 선택은 상세에서만 가능하다. 도해는 테마의 텍스트·강조색을 사용하므로 야간에는 적색이다. 좁은 화면에서 썸네일은 56px, 나머지 텍스트는 줄바꿈 가능한 영역이다.

전용 단위 검증은 전체 121개 커버리지, RA 경계·북/동 방향, 30개 별자리 선 보존, 모든 투영점의 프레임 내부 위치, 사진과 도해 구분, 오류 fallback, 읽음 배지, 상세 크레딧·야간 보호·태양 안전 순서를 다룬다. 실제 휴대폰 검증을 대신하지 않는다.
