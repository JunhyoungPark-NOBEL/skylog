# 시야 고정과 이동 전환 — beta.24 / build30

2026-09-13. main/origin `9deeff2` 일치를 확인하고 시작했다. 사용자는 이전 개선에도 S24+ 설치 앱의 정지·확대 상태에서 떨림을 느낀다고 보고했다. 아래 수치는 합성 시험이며 실기기 측정이 아니다.

## 구현과 원인

- ‘화성으로’ 같은 목표 버튼을 불투명 강조색으로 바꾸고 바로 옆에 44×44px 취소 X를 두었다. 육안·망원경 안내 모두 적용한다. 야간에는 적색 팔레트를 따른다. 상단 중앙 한 줄과 접힌 추가 메뉴를 유지한다. 육안 목표의 추가 메뉴에는 상세 정보와 해당하는 경우 뜨는 시각/시간 이동을 제공한다.
- 이전 처리는 입력을 부드럽게 만들었지만 시점을 고정하지 않았다. `min(0.025°, degPerPixel×0.2)`의 작은 출력 차단 범위는 확대 시 더 작아졌고, 남은 움직임이 계속 카메라로 전달됐다. 합성 입력을 줄여 보이는 것만으로 실제 손의 왕복 움직임을 해결했다고 판단할 수 없었다.
- 표시용 `IntentStabilizer`를 측정 필터 뒤, 40ms 표시 보간 앞에 추가했다. 정지 중에는 마지막 시야를 고정한다. 범위 밖에서 한 방향의 이동이 지속될 때 추종하고, 이동이 멈추면 현재 출력 자세에서 다시 고정한다. 이동 판정용 100ms 저역 통과와 약320ms 궤적을 사용해 빠른 왕복을 순방향 이동과 구별한다. 작은 전환은 100ms에 걸쳐 이득을 높이며 큰 회전은 빠른 경로로 처리한다.
- 고정 범위는 FOV90°에서1.05°,15°에서0.425°,3°에서0.325°다. 단순히 초점 방향을 맞히는 필터가 아니라 작은 입력에는 움직이지 않는 사용성 정책이다. 범위 안의 세밀한 조작이 즉시 반영되지 않으며, 의도 판별을 보장할 수 없다. 느린 드리프트와 지속적인 큰 손목 흔들림은 의도한 움직임처럼 보일 수 있다. 실제 광학 정렬 정확도와 화면 안정성은 구분한다.
- 이 고정값은 카메라 표시 전용이다. 원래 센서 측정, 세 별 보정의700ms 평균/잔차, 물리 +Y 경통 축과 상대 센서 기준을 변경하지 않는다. GPS/수동 전환은 표시 이력도 초기화하며 기존 별 탭은 센서를 끄지 않는다.
- 확대 화면에서는 별 위치를1초 간격으로 갱신하는 것 자체도 미세한 계단 이동을 만든다. 0.08px 이동 예산에 따라 갱신 간격을40~1000ms로 정한다. 412px 폭·FOV3°에서는 약97ms다. 현재 시각이 정지된 경우 추가 계산/그리기를 하지 않는다.
- 검색에서 즉시 안내에 진입하면 하늘 카탈로그 준비 전에 읽은 내부 ID가 이름으로 남는 오류도 수정했다. 준비된 씬에서 이름과 지평선 아래 천체의 자료를 읽는다.

## 자동 검증

시작 시 install·typecheck·기존798개 단위 검사 통과. 구현 후 typecheck·ESLint·단위813개(117파일)·PWA 빌드 통과. 전체 브라우저115개 중114개 통과 후 새 화성 검사에서 위 이름 초기화 오류를 발견했다. 수정 후 관련8개 모두 통과했다. 정상·야간 목표 색 대비4.5:1 이상, 취소44px, 360px·200% 글자 배치의 스크린샷을 직접 확인했다. 브라우저의 세 별 보정/재사용과 확대 별 선택·GPS 유지, 정지 시 draw0도 통과했다.

합성 입력: 30/60/90Hz, 불규칙 간격±12%, 화면120Hz, 412×915px. 세 축의 빠른 진동과 느린 손목 흔들림을 합쳤다. 동일한 측정 필터 출력에 대해 기존40ms 표시와 고정 범위 적용 표시를 실제 카메라/별 투영으로 비교했다. 초기4초 제외, 평균 위치 주위의 RMS이며 절대 포인팅 오차가 아니다.

이는 시험 입력이 고정 범위에 머물렀다는 결과다. S24+에서 모든 떨림이 사라졌다는 뜻은 아니다. [원본 수치](benchmarks/intent-stability-build30.json).

추가로 손떨림을 섞은1/5/30°/s 이동·반전·정지(다시 고정, 잔여각도 제한), 작은 왕복, 1° 이동 시작의 급격한 전환, 45° 단발 이상값, 90° 큰 회전, 359/0°·천정 근처·roll·중복/역순/부호 반전/재연결/확대/수동 전환을 검사했다. 느린1°/s 움직임은 고정 범위를 넘어야 반영되며 관련 합성 시험에서2초 안에 추종을 시작했다. 확대·정지 시야의 천체 계산 갱신은 실제 천문 래퍼로 검사했다.
