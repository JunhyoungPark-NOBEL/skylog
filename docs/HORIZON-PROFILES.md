# 지평선·공개 프로필·보상 이관

2026-09-11 · beta.17 / build23 준비

첫 하늘과 프로필이 같은 배경·지면·장식을 사용한다. 프로필에는 아바타도 함께 보이며 사진·댓글의 작성자 옆에는 아바타 초상만 표시한다. 공개 동기화한 작성자 프로필을 열면 관측 풍경을 볼 수 있다.

## 선택과 해금

장식20개 중 신규 기본 지급은 남쪽 벤치1개다. 주택·관측 데크·강아지를 추가했으며 식탁·정자, 쌍안경 거치대와 여러 굴절·반사·돕소니안·슈미트 카세그레인·전파망원경·관측소 돔을 유지한다. 푸른 언덕은 기본 배경이다. 바위산은 퀴즈 스테이지5개, 설산은 서로 다른10일 관측, 바다는 새 퀴즈5문제 첫 시도 연속 정답으로 얻는다. 지면4개 중 잔디는 기본이고 나머지는 업적으로 얻는다.

배경 카드는 잠겨 있어도 그림을 보여 주고 눌러 전체 미리보기를 연다. 미리보기는 저장하거나 소유권을 지급하지 않는다. 획득한 배경의 이름 버튼으로만 적용한다. 닫기·Escape 후 원래 카드로 초점을 돌려준다. 작은 화면에서는 배치·배경·지면·표시4개 탭으로 구분한다.

보상은 DECORATIONS, GROUND_STYLES, BACKDROP_STYLES, AVATAR_REWARDS가 실제 활성 배지ID를 참조한다. 유료 재화·무작위 뽑기·별도 꾸미기 결제는 추가하지 않는다.

## 기존 기록과 백업

기존 progress/personal.profile에 선택ID인 backdrop을 추가한다. 빠진 값은 field다. 이름·아바타·보관 코디·다섯 슬롯·지면·표시·크기를 유지한다. backdrop.reward:<id> 등 보상 행은 유효한 earnedAt만 인정하며 한 업적의 장식·지면·배경·아바타 보상을 같은 트랜잭션으로 지급한다.

선택 목록에서 없앤 flowers·sunflowers는 house, stones는 observing-deck, fern은 dog로 정규화한다. 이미 받은 이전 보상 행은 삭제하거나 다시 쓰지 않고 새 소유권으로 읽는다. 이전 배치와 백업도 같은 규칙을 따르며 두 예전 항목이 같은 새 항목이 되면 첫 자리만 유지한다.

personal.ownership-v2로 기존 사용자 여부를 최초 저장 때 고정하는 정책은 유지한다. 이전 기본 지급품은 새 장식으로 이어지고 신규 사용자에게는 자동 지급되지 않는다. 읽기만으로 사용자 데이터를 변경하지 않는다. 아바타·지평선 동시 저장은 서로 덮어쓰지 않으며 새 배경과 보상도 기존 JSON 백업으로 복원된다.

## 공개 프로필

sky_members.horizon은 허용된 선택ID와 표시 설정만 담는다. 이전4키 객체와 backdrop을 추가한5키 객체를 모두 받으며 이름·좌표·외부URL·임의SVG·알 수 없는 키는 거부한다. 구버전 장식ID4개도 서버에서 허용하고 새 클라이언트가 새 장식으로 표시한다. 로그인 계정 일치·활성 회원·본인행 RLS 검사, 예전3인자 RPC의 기존 지평선 보존 정책은 유지한다.

업데이트만으로 로컬 풍경을 공개하지 않는다. 사용자가 ‘이 모습으로 공개 동기화’를 누를 때만 전송한다. 계정 변경과 편집 중인 로컬 배치는 이전 요청 응답·공개 스냅샷과 분리한다.

202609110002_horizon_scenery.sql은 기존 validator의 허용ID만 확장한다. root가 연결된 Supabase 프로젝트에 적용했고 회원1명·사진0개·댓글0개·공개지평선0개 및 기존 회원전체 지문을 보존했다. 함수지문은 로컬과 같고 RLS·익명쓰기차단·회원쓰기·새풍경 검증을 확인했다. 근거는 artifacts/qa-build23/community-server-verification.json이다. 실제 사용자 프로필을 대신 게시하지 않았다.
