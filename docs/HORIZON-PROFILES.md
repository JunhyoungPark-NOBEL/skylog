# 지평선 꾸미기·공개 프로필·보상 이관

2026-09-11 · beta.15 / build20

기존 독립 마당을 첫 하늘 화면의 지평선과 연결한다. 프로필에는 같은 장식과 아바타를 함께 보여 주고, 사진·댓글 작성자 옆에는 아바타 초상만 표시한다. 작성자 프로필을 열면 공개 동기화한 지평선도 보인다. 사진 목록 카드의 작성자는 중첩 버튼을 만들지 않으며 사진 상세에서 프로필을 연다.

## 장식과 해금

장식21개 중 신규 사용자 기본 지급은 벤치1개다. 나머지20개는 실제 학습·관측 업적에 연결한다. 벤치·식탁·정자와 쌍안경 가대·기본 굴절·장초점 굴절·뉴턴 반사·돕소니안·슈미트카세그레인·전파 안테나·관측소 돔을 포함한다. 지면4개는 잔디가 기본이며 모래·돌·눈은 업적으로 얻는다. 아바타 보상은12개에서28개로 늘렸다. 외모의 기본 정체성을 정하는 피부·머리·표정 선택은 계속 기본 제공한다.

보상은 `DECORATIONS`, `GROUND_STYLES`, `AVATAR_REWARDS`가 실제 활성 배지 ID를 참조한다. 연속 퀴즈 정답 조건은 서로 다른 문제를 처음 풀었을 때의 연속 정답이다. 문제를 반복 제출해서 즉시 해금하는 것으로 안내하지 않는다. 유료 재화·무작위 뽑기·별도 꾸미기 결제는 추가하지 않는다.

## 저장과 기존 사용자

DB 스키마를 늘리지 않고 기존 `progress`의 `personal.profile`에 `ground`, `sceneryEnabled`, `sceneryScale`을 추가한다. 기존 다섯 `slots`, 이름, 아바타와 보관 코디를 보존한다. `ground.reward:<id>`는 타임스탬프가 유효한 지급만 인정한다. 한 업적이 주는 지면·장식·아바타는 같은 트랜잭션에서 지급한다.

`personal.ownership-v2`의 `{ version:2, legacy:boolean }`로 최초 저장 시 기존 사용자 여부를 고정한다. 과거 프로필 또는 보관 코디가 있으면 예전 기본 제공 목록을 유지한다. 새 사용자는 처음 저장하거나 빈 코디를 삭제한 뒤에도 신규 잠금이 유지된다. 실제로 획득한 보상도 회수하지 않는다. 읽기만으로 사용자 기록을 변경하지 않는다. 코디와 지평선의 동시 저장은 서로의 다른 필드를 덮어쓰지 않으며 기존 JSON 백업에 함께 포함된다.

## 공개 프로필

`sky_members.horizon`은 선택 ID·크기·표시 설정만 담는다. 전체 키4개, 슬롯5개, 중복 없는 허용 장식만 허용하고 이름·좌표·외부 URL·임의 SVG를 받지 않는다. `sky_update_profile_v2`는 로그인 계정 일치·활성 회원·기존 본인 행 RLS를 검사하는 security-invoker 함수다. 예전3인자 RPC도 유지하여 구버전 앱이 저장한 지평선을 지우지 않는다.

기존 프로필의 horizon은 null이며 이번 업데이트만으로 사용자의 꾸미기를 공개하지 않는다. 사용자가 공개할 닉네임·모습을 확인하고 ‘이 모습으로 공개 동기화’를 누를 때만 저장한다. 계정이 바뀌면 이전 응답은 새 계정 편집값에 반영하지 않는다. 수정 중인 로컬 배치는 이미 전송 중인 공개 스냅샷과 분리한다. 한영 개인정보 안내에 새 공개 항목을 반영했다.

마이그레이션 `202609110001_horizon_profiles.sql`을 기존 연결된 Supabase 프로젝트에 트랜잭션으로 적용하고 이력을 기록했다. 기존 회원1명·사진0개·댓글0개를 보존했으며 기존 회원 행의 지문도 일치했다. RLS 활성·익명 RPC 불가·회원의 정지 상태 수정 불가를 확인했다. 운영 DB의 세 함수 본문을 공백 정규화한 지문은 로컬 SQL과 모두 일치한다. 공개 지평선은0개로 유지했고 실제 사용자 프로필을 대신 게시하지 않았다. 검증 근거는 `artifacts/qa-build20/community-server-verification.json`이다.

## 확인 범위

보상 잠금·이관·동시 저장·백업·잘못된 입력, 명시적 공개 동기화·계정 변경·프로필 대화상자의 초점 복귀를 단위 검사한다. 로컬 PostgreSQL32개 검사는 새 아바타8종 저장과 유효하지 않은 입력 거부·다른 회원 행 변경 차단·구버전 RPC 보존을 포함한다. 모바일 브라우저에서는 실제 퀴즈 답 재채점 해금·작은 화면·영어125%·야간·재실행을 확인한다.
