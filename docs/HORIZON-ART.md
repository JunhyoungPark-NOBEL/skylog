# 지평선 꾸미기 그림과 렌더링

2026-09-11 · 기존 별/지평 좌표와 관측 가능성 계산은 유지한다.

## 공용 그림

`src/personal/horizonArt.ts`에서 21개 장식을 직접 SVG로 그린다. 기존 12개와 식탁·정자·쌍안경 가대·장초점 굴절·반사·돕소니안·슈미트 카세그레인·전파 안테나·관측소 돔 9개다. 목재와 무광 경통, 성긴 지면 무늬를 사용하며, 외부 사진·생성 이미지·CDN을 읽지 않는다. 저장소 자체 MIT 코드에 포함된다.

- `decorationSvg(id)`: `-64 -112 128 128` 좌표계의 내부 `<g>`. 발끝은 y=0이며, 물품 목록과 프로필·실제 하늘이 같은 원본을 쓴다.
- `horizonPanoramaSvg({ slots, ground, sceneryScale }, { night?, idPrefix? })`: 프로필용 전체 SVG, `0 0 1200 280`. 하늘 부분은 투명하며, 아바타는 프로필 UI에서 따로 겹친다. ID 접두사는 안전 문자만 남기고, 사용자 이름이나 메모는 SVG에 넣지 않는다.
- `horizonAtlasSvg({ slots, sceneryScale })`: 하늘용 4096×128 아틀라스. 360도에 한 번만 놓으며 북쪽 경계에 장식을 반복하지 않는다. 실제 SVG 좌표계는 5120×128로 고정하고 래스터 폭만 4096으로 제한한다.
- `HORIZON_SLOTS`: 다섯 방위 108°·144°·180°·216°·252°. 프로필의 x=120·360·600·840·1080에 대응한다. 처음 받는 벤치는 남쪽인 세 번째 칸에 놓는다.
- 지면은 잔디·모래·돌·눈의 공용 세 가지 색 팔레트를 사용한다. 실제 하늘의 무늬는 셰이더로 그려 추가 이미지가 필요 없다.

## 하늘에서 보이는 범위

그림은 기존 아래 반구 지면 재질 안에서 합성한다. 카메라를 따라 움직이는 화면 배너가 아니며 실제 방위에 고정된다. 지면 꼭짓점은 고도 0도 이하이고, 장식 아틀라스의 위쪽도 고도 -0.45도 아래로 제한한다. 따라서 어떤 투영·기기 방향·줌에서도 0도 위의 천체를 덮지 않는다.

작은 크기는 9도, 큰 크기는 12도 높이의 영역을 쓰며 각 장식의 여백에 따라 실제 그림은 더 작다. 각 위치 사이가 36도여서 조밀하게 겹치지 않는다. 같은 지평 좌표를 이용하므로 줌아웃할 때도 천구 원의 클리핑을 따른다. 신규 360×760 화면의 기존 기본 시점(고도45°/방위180°/시야90°)에서 벤치가 시간/탭 UI 위에 보이는 것을 확인했으므로 초기 카메라를 바꾸지 않았다.

지면과 장식을 먼저 하나의 색으로 합친 뒤 사용자의 지면 불투명도를 한 번 적용한다. 지면50%일 때 장식만75%가 되는 이중 합성을 만들지 않는다. 풍경 숨김·지평선 장식 숨김·아래를 볼 때의 기존 지면 페이드와 적색 야간 모드를 따른다. 지면 종류는 그대로 두고 장식만 숨길 수 있다.

## 저장·성능·복구

`SkyScene` 생성 때와 `progress`/`all` DB 변경 때만 정규화된 개인 설정을 읽는다. 요청 순번으로 늦게 끝난 읽기를 버리고 씬 해제 때 구독을 제거한다. 실패하면 현재 지면을 유지하며 다음 알림에서 재시도한다.

배치 또는 크기가 바뀔 때만 SVG 이미지와 GPU 아틀라스를 갱신한다. 지면 색·주야·카메라·센서 프레임은 uniform만 바꾼다. 새 요청은 이전 이미지 콜백을 취소하고, 교체된 텍스처는 즉시 해제한다. 해제 후 도착한 콜백도 무시한다. 외부 텍스처 로더와 예전 meadow-v2.webp를 더 이상 사용하지 않는다. 기존 지면 메시 안에 들어가므로 장식에 따른 드로콜이 추가되지 않는다.

WebGL 컨텍스트 복구는 Three.js가 현재 이미지에서 다시 업로드하고 씬이 다시 그리게 한다. 컨텍스트 이벤트 리스너도 씬 해제 때 제거한다.
