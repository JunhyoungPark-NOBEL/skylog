# 지평선 꾸미기 그림과 렌더링

2026-09-11 · beta.17 / build23 준비. 별·지평 좌표와 관측 가능성 계산은 유지한다.

## 공용 그림

`src/personal/horizonArt.ts`에서 장식20개와 배경4개를 직접 SVG로 그린다. 주택·관측 데크·강아지·벤치·식탁·정자와 서로 다른 관측 장비 등을 포함한다. 들꽃·해바라기·조약돌·풀숲은 선택 목록에서 제거하고 이전 소유권과 배치는 새 장식으로 이어진다. 목재·무광 경통·차분한 초록·청록·아이보리를 사용한다. 외부 사진·생성 이미지·CDN은 필요 없으며 저장소 MIT 코드에 포함된다.

- `decorationSvg(id)`: `-64 -112 128 128` 좌표계의 내부 `<g>`. 발끝은 y=0이며 목록·프로필·실제 하늘이 같은 원본을 쓴다. 강아지만 장면 배치에서0.6배로 줄여 건물과 크기를 맞춘다.
- `horizonPanoramaSvg({ slots, ground, backdrop?, sceneryScale }, { night?, idPrefix? })`: 프로필용 SVG `0 0 1200 280`. 실제360도 배경의 남쪽180도 구간을 사용한다. 아바타는 UI에서 따로 겹친다. 사용자 이름·메모는 SVG에 넣지 않는다.
- `horizonAtlasSvg({ slots, ground?, backdrop?, sceneryScale })`: 하늘용4096×256 아틀라스. 원본 좌표계는5120×280이고360도에 한 번만 놓는다. 북쪽 경계에 물품을 반복하지 않는다.
- `HORIZON_SLOTS`: 방위108°·144°·180°·216°·252°. 프로필x=120·360·600·840·1080에 대응한다. 기본 벤치는 남쪽 세 번째 칸이다.
- 배경은 푸른 언덕·바위산 능선·눈 덮인 산맥·고요한 바다. 먼 능선, 밝고 어두운 산면, 청록 바다와 해안선, 가까운 마당 순으로 겹친다. 작고 반복적인 풀·돌 무늬는 쓰지 않는다.
- 지면은 잔디·모래·돌·눈4가지다. 바다의 모래 해안과 지면 선택은 별도이며 잔디 해안도 만들 수 있다.

## 실제 하늘의 범위

기존 아래 반구 지면 재질 안에서 합성한다. 화면 배너가 아니며 실제 방위에 고정된다. 지면 꼭짓점은 고도0도 이하, 아틀라스 위쪽은 고도-0.45도 이하로 제한한다. 위아래 같은 각도 척도에 따라 배경 영역은19.6875도(약20도)이며 물품은 그 안의 작은 부분을 차지한다. small/medium은 배경 높이 대신 물품 크기를 바꾼다. 각 자리 사이36도 간격을 유지한다.

산봉우리 위 투명 영역에 지면 단색이 칠해지지 않도록 알파 덮임을 사용한다. 산 틈에서는 실제 하늘이 보이며 아래쪽은 기본 지면으로 부드럽게 연결된다. 0도 위 천체는 어떤 시선·줌에서도 덮지 않는다. 신규360×780의 기본시점 고도45°/남쪽/시야90°에서 능선과 벤치가 하단 UI 위에 나타난다. 초기 카메라는 바꾸지 않았다.

배경·장식·지면을 먼저 하나의 색으로 합친 뒤 지면 불투명도를 한 번 적용한다. 풍경 숨김·꾸미기 숨김·아래를 볼 때의 지면 페이드·적색 야간 모드를 따른다. 원형으로 줌아웃해도 기존 지평 클리핑을 유지한다.

## 저장·성능·복구

SkyScene 생성과 progress/all DB 변경 때만 개인 설정을 읽는다. 요청 순번으로 오래된 읽기를 버리고 씬 해제 때 구독을 제거한다. 실패하면 현재 지면을 유지하며 다음 알림에서 재시도한다.

배치·물품 크기·배경·지면을 아틀라스 캐시 키로 사용한다. 이 값이 바뀔 때만 SVG와 GPU 텍스처를 만든다. 주야·투명도·카메라·센서·표시 토글은 uniform만 바꾼다. 새 요청은 이전 이미지 콜백을 취소하고 교체 텍스처는 즉시 해제한다. 해제 뒤 도착한 콜백도 무시한다. 같은 지면 메시 안에 합성하므로 물품 수에 따른 드로콜 증가는 없다. WebGL 컨텍스트 복구 때 Three.js가 현재 이미지에서 다시 업로드한다.
