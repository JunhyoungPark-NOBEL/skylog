# 마당·아바타·천체 사진 커뮤니티 확장안

> 2026-09-08 · 사용자 요청에 따른 후속 설계안. beta.6은 풍경만 개선한다. 계정·꾸미기 보상·사진 게시·댓글·결제 서버는 아직 없다. 실제 지형과 장식 마당을 구분한다.

## 제품 경험

관측이나 퀴즈를 마치면 작은 꾸미기 아이템을 얻고, 내 마당과 아바타에 적용한다. 천체 상세에서 다른 사람의 사진을 보고, 내 관측 사진도 해당 천체에 공유한다. 초보자의 첫 달 사진도 환영하는 관측 모임을 목표로 한다.

하단 탭은 현재 다섯 개를 유지하는 방향을 제안한다. 배우기/기록의 프로필 진입점에 **내 마당**, 천체 상세에는 **이야기 · 모두의 사진**을 둔다. 사진 화면에서 **행성 · 성운 · 별 · 은하 · 달**로 좁히되 기존 ObjectId가 실제 대상 연결의 기준이다. 참여량이 충분해지면 커뮤니티 전용 화면을 따로 검토한다. 한 화면에 업적·상점·피드·퀴즈를 다시 쌓지 않는다.

## 단계와 출시 조건

| 단계             | 사용자가 할 수 있는 일                                                  | 완료 확인                                                                             |
| ---------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1. 내 마당       | 기존 업적으로 작은 꽃·돌길·망원경 장식을 얻고 배치, 아바타 색/의상 선택 | 기존 업적·백업·진도 보존, 중복 보상 없음, 오프라인·한영·큰 글자·야간 사용 가능        |
| 2. 모두의 사진   | 계정 생성, 천체별 사진 열람/공유, 내 사진 공개 범위·장비 정보 편집      | 업로드/삭제/신고/차단/운영자 검토/계정 삭제가 모두 작동한 뒤 제한된 베타              |
| 3. 따뜻한 댓글   | 사진 아래 한 단계 답글, 도움/축하 반응                                  | 신고 처리 담당자·처리 기한·이의 신청과 스팸 억제 검증 후 공개                         |
| 4. 선택형 유료화 | 마당/아바타 테마 팩, 이후 원본 보관·동기화 구독                         | 실제 상품/복원/환불·운영비·날씨 상업 이용 해결. [유료화안](MONETIZATION-PLAN.md) 참고 |

꾸미기 1단계는 서버 없이 먼저 개발할 수 있다. 소셜 공개 시점은 계정과 운영 도구가 갖춰지는 시점으로 정한다. 이 문서만으로 해당 태스크를 완료 처리하지 않는다.

## 꾸미기와 공정한 보상

- 예: 첫 관측 → 작은 데이지 화분, 스타호핑 첫 코스 → 길잡이 표지, 망원경 기초 완주 → 미니 망원경. 기존 조건/배지 ID와 연결하며 외형이 관측 정확도나 퀴즈 점수에 영향을 주지 않는다.
- 업적 전용 아이템은 성취의 증표로 유지한다. 판매용 테마와 획득 경로를 구분하고 점수·정답·순위·추가 시도를 팔지 않는다. 랜덤 유료 상자와 유료 연속 학습 복구도 초기 범위에서 제외한다.
- 획득 알림은 결과 화면에 작은 카드 한 장: “첫 관측을 남겼어요. 마당에 데이지를 놓아 볼까요?” → “꾸미기” / “나중에”. 관측 중 화면을 덮지 않는다.
- 내 마당은 독립 편집 화면을 기본으로 한다. 하늘에 장식을 보이게 하더라도 낮은 장식 구역만 허용하며 끄기·초기화·아래 시선 투명화를 유지한다. 광학 시야·가이드 화살표·목표를 가리지 않는다.
- 드래그 외에도 아이템 선택→위치 버튼→확정으로 배치할 수 있어야 한다. 색 외에 이름/획득 경로를 표시하고 동작 줄이기·44px 이상 조작부·한영 문장을 지원한다.
- 데이터 초안: item catalog와 inventory, yard layout, avatar appearance를 분리. 보상 부여의 고유 키는 (소유자, 업적 ID, 보상 버전). 백업 재가져오기/다중 기기 동기화가 같은 보상을 중복 지급하지 않아야 한다. 스키마 변경은 다음 구현에서 DB 마이그레이션과 함께 한다.
- 로컬 성취는 개인 꾸미기에 사용할 수 있지만 공개 경쟁의 검증 자료로는 부족하다. 미래 리더보드는 서버가 확인한 퀴즈 세션을 별도로 설계하고, 백업의 점수·유료 여부로 순위를 올리지 않는다.

## 천체 사진 공유

천체 상세 → 모두의 사진 → 사진 공유 → 대상/사진/설명/공개 범위 확인 → 게시 순서다. 기기 내 관측 사진을 저장한 것만으로 공개하지 않는다. 초안은 비공개이며 공개 게시에는 명시적인 동작이 필요하다.

대상은 ObjectId로 연결한다(예: planet:saturn, dso:M42). 사진 종류/대상 자동 제안이 생겨도 사용자가 확인한다. 장비·노출·필터·촬영일·대략적인 지역은 선택 입력이며 실제 천체 식별을 자동으로 검증했다고 표시하지 않는다.

실제 촬영, 여러 장 합성/보정, 창작/AI 이미지는 표시를 구분한다. AI 이미지를 “내가 촬영한 사진” 목록에 섞지 않는다. 사진의 저작권은 작성자에게 두고 서비스 표시·썸네일 제작에 필요한 범위의 허락만 받는 약관을 준비한다. 남의 사진 재업로드 신고와 삭제 요청 경로를 둔다.

공개 파생 이미지는 서버에서 다시 인코딩하고 GPS/EXIF를 제거한다. 정확한 관측지 좌표와 원본 메타데이터는 기본 공개하지 않는다. 원본 보관을 제공하면 별도 비공개 저장소와 소유자 접근 제어를 적용한다. 파일 종류·용량·해상도 상한, 변환 작업 시간 제한, 서명 URL 만료, 요청 속도 제한을 두고 검토 전 파일은 공개 주소에 놓지 않는다. 공개 피드/차단/삭제 규칙은 서버가 확인한다.

## 댓글이 편안한 공간이 되려면

금칙어 필터만으로 깨끗한 댓글을 보장할 수 없다. 작성 전 간단한 안내, 신고·차단, 스팸 억제, 실제 검토 담당자가 함께 필요하다. Apple은 UGC 앱에 필터·신고 대응·사용자 차단·연락처를 요구하고, Google은 이용 규칙 동의와 지속적인 운영·신고/차단을 요구한다. [Apple 1.2](https://developer.apple.com/app-store/review/guidelines/), [Google UGC 정책](https://support.google.com/googleplay/android-developer/answer/9876937?hl=en)

제안하는 초기 댓글은 한 단계 답글과 “관측 성공 축하해요”, “장비 정보가 도움됐어요” 같은 반응이다. 처음부터 익명 채팅·DM·외부 링크·무제한 멘션을 열지 않는다. 휴대폰 사진과 고가 장비 사진을 같은 기준으로 줄 세우지 않는다.

신규 계정 작성 속도 제한, 반복 내용 탐지, 유해 표현 작성 전 재검토 안내를 적용한다. 자동 판정은 검토 대기/일시 제한을 보조하며 다수 신고만으로 영구 정지하지 않는다. 신고자는 다른 사용자에게 노출하지 않고, 작성자에게 조치 사유와 이의 신청 경로를 제공한다. 차단은 피드·댓글·알림·프로필 접점 전체에서 적용한다.

신고/차단/개인정보 보호는 무료다. 유료 회원도 같은 운영 규칙을 따른다. 운영자 화면에는 접수→검토→조치→이의 신청 이력이 필요하다. 공개 전 실제 담당자, 처리 시간 목표, 반복 위반 기준, 미성년자 범위·등급과 고객 연락처를 정한다. 자동화가 모든 괴롭힘을 없애 준다고 약속하지 않는다.

## 구현 전 수용 시나리오

- 기존 48개 업적/코스/기록을 유지한 채 새 보상이 부여된다. 같은 백업을 두 번 가져와도 수량이 늘지 않는다.
- 공개하지 않은 사진은 다른 계정/API/URL 추측으로 읽을 수 없다. 공개 사본에 GPS가 없고 원본은 비공개다.
- 게시물·댓글·계정 신고/차단/삭제가 기기 재실행·다른 계정에서도 일관되게 적용된다.
- 운영자가 조치·복구하면 감사 이력과 작성자 안내가 남는다. 오탐 이의 신청을 처리할 수 있다.
- 구독 종료/로그아웃 뒤에도 기기 내 기록 열람·내보내기를 막지 않는다. 개인정보 문서와 스토어 수집 신고를 실제 구현에 맞춘다.
