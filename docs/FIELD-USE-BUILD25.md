# S24+ 실사용 개선 — beta.19 / build25

2026-09-13. 기준: 연구실 main `b481144`(실행 코드 `a0225d3`, beta.18/build24). 사용자 확인 기기는 **Galaxy S24+ Android 설치 앱**이다.

## 변경과 원인

1. 별 선택은 추적을 유지한다. 이전에는 pointerdown 자체가 수동 전환이었다. 이제 6 CSS px를 넘는 한 손가락 이동에서만 전환하며 탭·핀치·취소를 구별한다. 별 선택은 손가락을 댄 순간의 화면을 사용한다.
2. 천정 부근의 방위각 180° 변화는 작은 3차원 회전에서도 나타날 수 있다. Euler 방위각 평활을 제거하고 쿼터니언으로 처리한다. OS가 1초 이상 25° 초과 방향 오차를 보고할 때만 안내하며 추적은 계속한다. 정확도를 보고하지 않는 기기를 정상 또는 불량으로 단정하지 않는다.
3. 하단 카메라 버튼으로 후면 영상을 겹친다. 영상 밝기10–90%·기기별 시야35–100° 조절. 별·글자는 선명하게 유지하고 가상 지면·은하수·하늘 배경은 숨긴다. 영상은 로컬 미리보기이며 저장·전송·오디오는 없다. 끄기·화면 이탈·백그라운드·권한 지연 응답·20초 시간 초과 때 트랙을 해제한다. 카메라 시야는 근사 조절이며 광학 왜곡을 푸는 정밀 영상 정렬은 아니다.
4. 수동 드래그는 이전 센서 롤을 갑자기 수평으로 돌리지 않는다. 화면의 시작점과 끝점에 해당하는 광선을 대응시켜 손가락 아래 천체가 따라온다. 천정에서 방위/cos(고도)로 생기던 회전을 없앴다.
5. 센서 설정에 **자이로 · 별에 맞추기**를 추가했다. Android `TYPE_GAME_ROTATION_VECTOR`, iOS `.xArbitraryZVertical`, 웹 `RelativeOrientationSensor`만 사용하며 자력계 소스로 자동 대체하지 않는다. 임의 북쪽을 표시하지 않고 밝은 별 정렬을 기다린다. 재시작·수신 중단 뒤 상대 보정은 다시 필요하다. 시간에 따른 드리프트는 재정렬로 고친다.
6. 평점·시상·투명도 입력 및 표시를 제거했다. 과거 저장 값은 편집·백업에서 보존한다. 공통 색·관측 난이도·분해된 정도, 행성/달/DSO 형태/분류된 이중성의 해당 항목만 제공한다. 과거 사용자 태그는 남기며 제거할 수 있다.
7. 흰색·회색·청백색·푸른색·황백색·노란색·주황색·붉은색 펜. 야간 모드는 화면만 적색으로 보여 원본 PNG의 색을 보존한다. 기록 상세에서 PNG 내보내기 또는 커뮤니티 초안을 선택한다. 개인 위치·메모는 넣지 않으며 게시 전 미리보기·동의를 거친다. 스케치는 기존 창작 유형으로 처리하므로 서버 스키마를 바꾸지 않는다.
8. 센서/보정 설정은 하단 오른쪽, 카메라는 하단 왼쪽이다. 5초 복귀 타이머를 제거했다. 수동 탐색 후 버튼으로 복귀한다.
9. 별의 분광형으로 추정한 색을 등급·거리와 함께 선택 카드/상세에서 제공한다. 자료 없는 별은 색 정보 없음으로 표시한다.
10. 별 크기와 색 대비를 높였다. 기존 확대 표시 옵션을 켰을 때 행성을 종전의 약2배로 그리고 목성 띠·화성의 밝은 극을 단순 도식으로 표시한다. 실제 자전 위상/촬영 영상이 아니며 태양·달의 크기/위상 규칙은 유지한다.
11. 네이티브 센서 요청 주기를30→60Hz로 높이고 필터 데드밴드를 화면0.35px 기준으로 조절한다. 렌더 프레임 보간은 유지한다. 밝기 우선권을1px 미만으로 줄여 가까운 별이 선택되게 했다. 탭 주변 원뿔 밖의 별을 먼저 제외하고 굴절·소광을 반영해 정밀 투영 비용과 보이지 않는 별 선택을 줄였다.

## 검증

타입·lint·단위/브라우저·네이티브 빌드의 최종 결과와 배포/서명 상태는 `plan/STATUS.md`의 build25 보고에 기록한다. 검증은 합성 센서와 브라우저/에뮬레이터이며 S24+ 하드웨어 성능 측정을 대신하지 않는다. iOS는 배포 서명 없이 컴파일한다.

## S24+ 확인

- 센서 켜짐 상태에서 별 탭·핀치 확대 후 추적이 유지되는지, 확대 상태의 원하는 별이 선택되는지.
- 천정과 천정을 가로지르는 움직임에 갑작스러운 방향 전환/자석 경고가 없는지.
- 드래그를 시작하면 손가락 방향으로 움직이며 5초 이상 기다려도 수동으로 남는지, 하단 버튼으로 복귀하는지.
- 자이로 선택 → 실제 밝은 별을 화면 중심 십자에 맞춤 → 확인 → 다른 방향 추적. 앱을 다시 열면 새 정렬 안내가 나오는지.
- 후면 카메라 권한·밝기·확대·끄기·백그라운드 복귀. Android 카메라 사용 표시가 종료되는지.
- 토성/달/이중성/성운 기록 항목, 여러 색 스케치의 저장·다시 열기·내보내기. 커뮤니티는 게시를 누르기 전 공개되지 않는지.
