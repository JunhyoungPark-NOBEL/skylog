`preview.png`는 한눈에 보는 검토용이며 스크린샷 입력란에는 올리지 않는다. ZIP은 PC에서 압축을 푼 뒤 각 PNG를 업로드한다. AAB는 이 화면이 아니라 내부/비공개 테스트의 버전 생성 화면에 올린다.

휴대전화 화면은 실제 UI를 그대로 담고 상단 약 19% 영역에 소개 문구를 붙였다. 태블릿은 추가 홍보 문구 없이 앱 화면만 촬영했다. 업로드 이미지의 규격·용량·색상 형식과 글자 잘림을 확인했다. 이 검증은 파일 규격 확인이며 Google의 심사나 추천 노출을 보장하는 뜻은 아니다. [Google Play 시각적 애셋 안내](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en)

## 스타호핑과 향후 유료 안내

상세 설명과 휴대전화 네 번째 이미지에 망원경 관측자를 위한 스타호핑을 넣었다. 실제 기능인 밝은 기준별, 이동 방향·각거리, 단계별 차트, 장비별 시야 안내와 여섯 코스를 설명한다. 숙련된 관측자도 이용할 수 있지만 자동 천체 인식이나 망원경 모터 제어 기능을 의미하지 않는다.

현재 build17에는 결제·유료 잠금이 없으므로 이번 등록 문구에 유료 표시를 넣지 않았다. 실제 상품·구매·복원과 대상 기능을 적용하는 버전에서 본문 끝에 다음 한 줄을 추가한다.

> 일부 퀴즈와 망원경 코스는 별도 구매가 필요해요.

현재 계획인 난이도 2·3 퀴즈와 지정 망원경 코스에 맞춘 문구다. 기본 시야원과 장비 설정까지 유료로 확대해 표현하지 않는다. 가격 9,900원과 이용 기간·상품 형태는 이 묶음에서 확정하거나 등록하지 않았다. ‘작게’는 설명 끝의 짧은 안내로 반영하며 구매 조건을 읽기 어렵게 숨기지 않는다.

## 실제 화면과 촬영 범위

- 앱 소스: `830c974bebeab0e873925ba58b0bd8a01798de6e`, beta.12/build17의 native 정적 번들.
- 실제 제품 코드를 실행한 격리된 브라우저 화면이다. 실제 Android 휴대전화·태블릿에서 촬영한 사진이나 네이티브 실기기 검증은 아니다.
- 휴대전화 CSS 432×768, 배율 2.5. 태블릿 CSS 960×540@2와 1280×720@1.5.
- 위치는 앱의 공개 기본 예시인 대전, 하늘 시각은 2026-09-10 21:00 KST다. 개인 위치·계정·이메일·사용자 사진은 사용하지 않았다.
- 기록에는 ‘샘플 기록’으로 표시한 관측 예시 세 건을 격리된 브라우저에 넣었다. 실제 사용자의 후기나 검증된 관측 실적이 아니다.
- 아바타는 기본으로 열려 있는 옷·색·머리만 실제 UI에서 선택했다. 업적·유료 권한·보상을 조작하지 않았다.
- 피처 그래픽의 배경은 같은 앱이 렌더링한 하늘 캔버스다. 천체 사진은 실제 관측 자료이며 인공지능으로 만든 우주 사진이나 가짜 앱 UI를 넣지 않았다.
- 원본 화면·재현 스크립트·검증 보고서는 저장소에 보관한다. 실제 폰에서는 설치한 build17의 하늘·사진·스타호핑·기록·퀴즈·마당이 같은지 확인한다.
