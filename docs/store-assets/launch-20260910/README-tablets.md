# 태블릿 스크린샷 촬영 기록

`tablet-7/`, `tablet-10/`에 각각 4장, 총 8장의 실제 앱 화면을 저장했다. 모두 16:9 가로 1920×1080 PNG이며 알파 채널이 없는 RGB 이미지다.

| 파일                   | 화면                                   |
| ---------------------- | -------------------------------------- |
| `01-sky.png`           | 토성·별자리·은하수가 보이는 하늘       |
| `02-search-photos.png` | 메시에 천체 검색 목록과 실제 관측 사진 |
| `03-learning.png`      | 배우기 첫 진입의 퀴즈 여정             |
| `04-garden.png`        | 기록과 보상을 추가하지 않은 기본 마당  |

## 촬영 조건

- 앱: 스카이야드 `0.1.0-beta.12`, Android build 17.
- 앱 소스: `830c974bebeab0e873925ba58b0bd8a01798de6e`.
- 실행 대상: 최종 native 빌드의 정적 웹 번들, `http://127.0.0.1:5181/`.
- 브라우저: Playwright Chromium, 터치 가능한 새 컨텍스트, 한국어, Asia/Seoul, SwiftShader WebGL.
- `tablet-7`: CSS 뷰포트 960×540, 배율 2.
- `tablet-10`: CSS 뷰포트 1280×720, 배율 1.5.
- 하늘 샘플: 공개 기본 장소인 대전(KAIST), 2026-09-10 21:00 KST. 고도 45°, 방위 170°, 시야 95°.
- 로그인·개인 위치·개인 기록을 사용하지 않았으며, 학습 진도나 마당 보상을 임의로 채우지 않았다.
- 원래 앱의 UI와 사진을 그대로 촬영했다. 홍보 문구, 기기 프레임, 이미지 보정·합성은 추가하지 않았다.

**실제 7인치·10인치 기기에서 촬영한 화면은 아니다.** 위 크기의 브라우저 뷰포트에서 실제 앱을 실행한 화면이며, 실제 태블릿의 물리적 크기·PPI·운영체제 바까지 재현했다는 뜻은 아니다. 검색·학습·마당은 스크롤할 수 있는 실제 페이지의 현재 뷰포트만 담았다.

## 확인

최종 8장 모두 직접 열어 글꼴, 사진, 화면 구도를 확인했다. 자동 검사에서 1920×1080·RGB, 글꼴 로딩 완료, 화면에 보이는 이미지 로딩 완료, 가로 넘침 없음, 깨진 대체 문자 없음, 미완료 로딩 안내 없음, 콘솔 및 페이지 오류 0건을 확인했다. 하늘의 UI와 주요 천체 이름을 읽을 수 있고, 페이지의 첫 제목·주요 버튼이 잘리지 않았다.

파일별 크기·SHA-256 및 레이아웃 검사 결과는 `tablet-capture-report.json`에 기록했다. 촬영 스크립트는 `scripts/capture-store-tablets.mjs`다. 기본 주소에서 동일 번들을 제공한 뒤 저장소 루트에서 다음 명령으로 재촬영할 수 있다.

```sh
node scripts/capture-store-tablets.mjs
```

다른 주소는 `STORE_CAPTURE_URL` 환경 변수로 지정할 수 있다. 새로 촬영하면 각 파일과 보고서를 덮어쓰므로 승인된 제출본을 먼저 보관한다.
