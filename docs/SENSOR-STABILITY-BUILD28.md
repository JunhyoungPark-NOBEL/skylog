# GPS 방향 안정화 — beta.22 / build28

2026-09-13. 최신 main/origin 6f358ad(build27) 일치를 확인하고 시작했다. Galaxy S24+ Android 설치 앱의 광각·확대 손떨림 제보를 기준으로 수정했다.

## 구현 요약

- 하단 GPS 옆에 20px 나침반 아이콘을 추가했다. 일반 하늘과 망원경 안내에서 같은 모양을 사용하며 기존 버튼 위치, 44px 이상 터치 영역과 접근성 이름을 유지한다.
- 자세를 두 단계로 평활하며, 광각부터 안정화한다. 실제 계산에서 빠져 있던 방위 평활 설정도 세계 수직축 쿼터니언 분해에 적용한다. 천정이나 북쪽 경계에서 Euler 방위각이 뒤집히는 계산은 쓰지 않는다.
- 속도 판정 전에 잔떨림을 걸러 손떨림을 동반한 의도적인 이동이 정지로 오인되지 않게 했다. 단발 큰 방향 튐은 다음 샘플로 확인하고 실제 방향 전환은 빠르게 따른다. 확대에 맞춘 작은 출력 데드밴드는 유지한다.
- 센서 측정 시각을 앱·웹에서 끝까지 전달하고 화면은 40ms 뒤의 시간축을 보간한다. 이벤트가 몰려와도 보간을 매번 재시작하지 않는다. 오래된/중복 입력·공백·재연결을 검사하며 미래 방향을 예측해 그리지 않는다.
- Android 자동 모드는 가능한 기기에서 자력계를 쓰지 않는 게임 회전 벡터로 움직임을 추적하고, 절대 회전 벡터의 북쪽 오프셋만 8초 시정수로 천천히 보정한다. 동일 측정 시각끼리 비교하고 나쁜 정확도나 15° 초과 기준 변화는 반영하지 않는다. 게임 벡터 미지원·입력 중단은 기존 절대 소스로 복귀한다. 명시적인 자이로 모드는 계속 자력계를 쓰지 않는다. 웹/iOS에는 공통 필터·측정 시각·프레임 보간 개선을 적용한다.

## 검증과 개선 수치

기본 설치·타입·기존 단위772개 통과를 확인한 뒤 작업했다. 최종 typecheck·전체 lint·단위786개(113파일)·PWA 빌드·전체 브라우저113개 통과. 모바일 CI와 공개 배포는 아래 산출물 검증에 기록한다.

합성 입력을 실제 CameraController와 별의 CPU 화면 투영까지 통과시켰다. 412×915 CSS px, 센서30/60/90Hz와 렌더120Hz, 세 축의 0.9–12.3Hz 복합 입력을12초간 재생하고 초기4초를 제외해 측정했다. 휴대폰 실측치는 아니다. 재현 fixture와 전체12조건은 [벤치마크](benchmarks/sensor-stability-build28.json)에 있다.

| 시야각 (60Hz 입력) | 이전 잔여 RMS | 변경 후 잔여 RMS | 감소 |
|---|---:|---:|---:|
| 90° 기본 | 0.476px | 0.241px | 49% |
| 60° | 0.736px | 0.373px | 49% |
| 15° 확대 | 0.982px | 0.381px | 61% |
| 3° 최대 확대 | 2.895px | 0.794px | 73% |

모든12조건에서 잔여 RMS1px 미만·프레임 간 최대 이동0.5px 미만. 60Hz/3°의 프레임 간 최대 이동은1.475→0.205px다. 90° 전환은 필터와 렌더를 합해150ms 이내 수렴한다. 손떨림이 섞인5°/s 이동의 RMS 자세 오차0.6° 미만, 정지 후 재수렴도 검사했다. 25ms 지연/순서 뒤바뀜 입력의 일정 회전은40ms 재표본화에서 속도 오차0.01°/s 미만이었다.

네이티브 북쪽 융합에서는 ±4°/1.8Hz 방위 잡음의 잔여 오차0.1° 미만, 빠른 회전·천정 근처 자세·90° 이상치·작은 드리프트 회복·중복·재연결·구형 플러그인을 검사했다. 초기 정렬 없이 상대 방위를 실제 북쪽처럼 노출하지 않는다. 최종 방향 정확도는 기기/자기장에 의존한다. 금속 근처에서 기존 별 보정 또는 자이로 모드를 사용할 수 있다.

브라우저 검사는 별 선택 중 센서 유지, 수동 이동 후 버튼 복귀, 자동 켜기/권한 거부, 카메라, 망원경 +Y축/두 별 정렬/시야 원, 스크롤·기록·학습·오프라인을 포함한다. 360px/200% 글자 화면에서 GPS 나침반과 다른 조작이 겹치지 않는 것도 스크린샷으로 확인했다.

## S24+ 확인 항목

- [ ] 새 버전으로 업데이트하고 앱을 완전히 종료한 뒤 다시 연다. GPS 옆 나침반과 자동 추적을 확인한다.
- [ ] 90° 기본 화면과15°/3° 확대에서 밝은 별을10초간 바라보며 잔떨림을 비교한다. 잠깐 멈추면 화면도 안정되는지 확인한다.
- [ ] 천천히 상하좌우로 이동하고 빠르게 다른 방향을 본 뒤 멈춘다. 지나치게 뒤처지거나 멈춘 뒤 계속 미끄러지지 않는지 확인한다.
- [ ] 천정을 가로지르고 북쪽을 넘어서도 갑자기 뒤집히지 않는지, 별을 눌러도 센서가 유지되는지 확인한다.
- [ ] 카메라 겹치기 및 망원경 +Y 안내에서도 확인한다. 수동 드래그 후 GPS로 복귀하고 앱을 잠시 내렸다가 다시 켠다.
