# 네비게이션·세 별 캘리브레이션 — beta.23 / build29

2026-09-13. 최신 main/origin `da85317` 일치를 확인하고 시작했다. 사용자가 build28의 떨림이 많이 줄었다고 보고했다. 이는 정성적인 사용 피드백이며 S24+의 수치 측정으로 기록하지 않는다.

## 구현

- 상세 화면의 두 동작을 ‘육안 네비게이션’ / ‘망원경 네비게이션’으로 통일했다. 상단 중앙은 ‘포말하우트로’처럼 한 줄 목표 버튼이다. ‘토성으로’·‘달로’의 조사도 처리하며, 영어는 Toward …로 표시한다. 종료와 추가 옵션은 목표를 눌렀을 때만 보인다. 아래꺾쇠 메뉴를 펼쳐도 목표 위치가 내려가지 않는다.
- 망원경 진입 소개 카드와 상시 태양 방향 경고를 제거했다. 캘리브레이션은 망원경 모드 하단 GPS 옆에 둔다. 태양 자체의 광학 안내 차단 및 보정 후보의 태양 근접 제외는 유지한다.
- 폰의 물리 +Y(윗변)를 경통과 평행하게 고정하고, 실제 파인더 중심에 밝은 별 세 개를 맞춘다. 후보는 2.5등급 이내·고도25~75°·서로20~150° 간격의 별이다. 달·행성은 3별 보정 후보에서 제외한다. 원형 파인더 차트에 주변 별과 중앙 표식을 보여 주며 정립/도립 설정을 반영한다.
- 700ms 동안 연속 자세를 모아 평균을 낸다. 최소8개·시간폭400ms 이상의 같은 세션 입력이 필요하며 이동·부호 반전·중복시각·중단을 검사한다. 정지 허용각은 min(0.3°, 파인더 시야×0.05)이다. 세 별 전체로 상대 센서의 북 기준과 장착 축을 함께 추정한다. 잘못된 조합·퇴화된 배치·최대잔차 min(0.75°, 파인더 시야×0.2) 초과는 완료 처리하지 않는다.
- 첫 보정 장소를 고정하고 각 별 확인 시각의 실제 위치를 사용한다. 다른 목표의 위치는 현재 시각에 맞춰 다시 계산한다. 같은 장착 프로필/센서 공급자/실행 세션에서만 완료값을 재사용한다. 일반 하늘도 같은 센서를 구독해 목표 전환으로 자이로 기준이 재시작되지 않게 했다. GPS의 작은 위치 잡음(100m 이내)은 보정 장소를 바꾸지 않는다.

## 정확도와 재사용 범위

세 별의 잔차는 측정 간 일치도이며 절대 포인팅 정확도의 보증이 아니다. 휴대폰만으로 모터·엔코더가 있는 가대의 자동 추적이나 영구적인 초정밀도를 제공하지 않는다. 앱은 현재 경통 방향과 목표까지의 방향을 안내한다. 경통/폰을 같은 상태로 고정하고 센서가 계속 켜져 있는 동안은 새 목표마다 다시 보정할 필요가 없다. GPS 버튼으로 화면 추종만 멈춰도 완료된 센서 기준은 유지한다. ‘설치 종료’는 센서도 해제한다.

폰을 떼거나 장비 프로필/관측 장소를 바꾸거나 센서가 재시작되면 새 보정이 필요하다. 1.5초 입력 공백·백그라운드 중 센서 중단·앱 재실행의 임의 자이로 기준에는 이전 값을 적용하지 않는다. 시간이 지나 드리프트가 보이면 캘리브레이션의 ‘설치와 보정 정보’에서 다시 맞춘다. 센서 연속 재사용은 배터리를 사용하므로 관측이 끝나면 설치를 종료한다.

참고: [Android 방향 센서 문서](https://developer.android.com/develop/sensors-and-location/sensors/sensors_position)는 게임 회전 벡터가 자력계를 사용하지 않으며 수직축 드리프트가 가능하다고 설명한다. [Celestron SkyAlign 설명](https://www.celestron.com/pages/skyalign-technology)의 시간·장소·세 기준점 개념을 참고했지만, 제조사 제품의 알고리즘/코드를 사용하거나 동일한 성능을 주장하지 않는다.
