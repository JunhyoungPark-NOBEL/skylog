# 관측 지평선과 프로필

2026-09-11 · 마당을 첫 하늘 화면의 관측 지평선으로 연결한다.

- `내 프로필 → 지평선 꾸미기`에서 장식 배치·지면·표시를 나누어 편집한다. 남쪽을 중심으로 펼친 미리보기의 다섯 자리(108°·144°·180°·216°·252°)가 실제 하늘의 같은 방위와 연결된다.
- 새 사용자는 중앙 벤치 하나로 시작한다. 내 장식과 해금할 장식을 구분하고 관측 장비·가구와 소품·자연을 골라 볼 수 있다. 잠긴 항목에는 조건과 현재 업적 진도를 연결하며 선택을 막는다.
- 이미 놓은 장식을 고르면 선택한 자리로 이동한다. 저장 후 최신 상태를 다시 읽을 때까지 다음 편집을 막아 이전 배치로 덮어쓰는 일을 방지한다. 장식 숨기기는 배치를 지우지 않는다.
- 잔디·모래·돌·눈의 지면과 장식 크기 두 단계를 지원한다. 편집 미리보기는 숨긴 장식도 보여 주며 숨김 상태를 안내한다. 프로필 보기에서는 실제 표시 설정을 따른다.
- 프로필에는 지평선과 아바타가 함께 보인다. 작은 화면에서도 코디를 알아보도록 아바타는 전경에 크게 표시한다. 댓글은 기존 원형 `AvatarPortrait`만 사용한다. 공개 프로필은 명시적 동기화로 반영한다.
- `GardenArt`와 장식 카드는 렌더러의 `horizonArt.ts` 도안을 공유한다. 외부 이미지 없이 동작하며 SVG별 독립 ID와 적색 야간 필터를 사용한다. 장식은 실제 천체 좌표를 바꾸지 않는다.
- `badge-quiz-3/5/10` 설명은 새 문제를 첫 시도에 연속으로 맞히는 조건으로 표시한다. 단순 풀이 수나 숙련 문항 수로 표시하지 않는다.

## 검증

- 기존 아바타 편집 단위 9개, 지평선 편집 단위 4개. 기존 코디와 장식 보유를 업그레이드 사용자 fixture로 보존한다.
- 지평선 Chromium 3개, 기존 프로필 Chromium 2개. 새 사용자 기본값, 이동, 저장·재실행, 크기·숨김, 하늘 복귀, 퀴즈 답 기록을 재채점한 보상 해금, 한국어·영어 125% 작은 화면과 야간 색상 검사를 포함한다.
- 보상 검사는 실제 공개 문항의 유효한 답 기록을 격리된 테스트 IndexedDB에 만든다. 배지·소유권 플래그를 직접 주입하지 않고 실제 계정이나 서버에 쓰지 않는다.
- 증거: `artifacts/qa-build20/profile-earned-ko.png`, `profile-horizon-en-large.png`, `profile-horizon-night.png`, `community-horizon-*.png`.
- 실제 휴대폰에서는 기존 코디 유지, 센서 이동 중 장식 방위 고정, 크기·숨김 재실행 보존, 낮은 천체를 가리는 정도를 확인한다. 브라우저 검증은 물리 휴대폰 검증과 구분한다.
