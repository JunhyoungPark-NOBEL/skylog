# 실제 천체 사진 — 출처·권리·관측 영역 보존

확인일: **2026-09-09**. beta.10/build15용 사진은 **164개 천체, 328개 WebP, 11,787,848 bytes**다. 메시에 110개와 추가 DSO 43개, 태양·달과 행성 7개, 시리우스·베텔게우스를 포함한다. 서로 다른 원본 관측 이미지 URL은 162개다. M42/M43과 NGC4038/4039는 각각 같은 관측 모자이크를 공유한다. 없는 천체에 다른 사진을 대신 연결하지 않는다.

모든 사진은 관측 기관이 공개한 실제 관측 자료다. AI 생성 그림·상상도·가짜 별·추가 합성은 사용하지 않았다. 파장별 색 합성이나 탐사선 모자이크 등 원출처가 이미 처리한 표현은 각 캡션에 구분해 설명한다.

작은 검색·선택 사진과 오늘 밤의 추천·관측 계획·오늘의 볼거리에서 상세 화면을 열 수 있고, 상세 사진 바로 아래에는 전체 원문 크레딧·출처·권리 정책·권리 판단·가공 내역을 표시한다. 오늘 밤의 천체 사진도 검색과 같은 썸네일·야간 보호를 사용하며, 사진이 없거나 읽기에 실패하면 기존 종류 기호를 표시한다. 관측 상태와 계획 저장의 별 버튼은 유지한다. 앱 정보에도 전체 164개 목록을 둔다. 작은 사진에서 긴 크레딧을 숨기려는 목적으로 기존 ESA/Hubble·ESO 정책을 넓게 해석하지 않았다. 현재 배포 묶음은 그 원본들을 교체했으며 사용하지 않는 WebP가 없다.

NASA 도메인에 있다는 사실만으로 모든 사진을 public domain으로 분류하지 않는다. 제3자 저작물, 상표·기관 로고, 특정 기관의 앱 보증은 별개다. DSS·상업 재사용이 불명확한 개인 사진·출처 불명 패널을 일괄 내려받지 않았다. 정책 비교와 제외 근거는 [권리 조사](../plan/research/2026-09-09-photo-expansion-rights.md)를 참고한다.

시리우스는 [NASA 공식 개별 자료](https://science.nasa.gov/asset/hubble/the-dog-star-sirius-and-its-tiny-companion/)와 [NASA/IPAC AstroPix STScI 2005-36a](https://www.astropix.org/image/stsci/2005-36a)의 제작·큐레이션·발행 기관을 대조했다. 베텔게우스는 [STScI의 1996년 공식 공개 자료](https://hubblesite.org/contents/media/images/1996/04/394-Image.html)를 사용했다. 공동 연구자 이름이 있다는 이유로 크레딧을 줄이지 않았고, 2008년부터의 기여자 정책을 과거 자료에 소급 적용해 권리의 유일한 근거로 삼지도 않았다.

## 파일·크롭·색

- 배포 위치는 호환성을 위해 `public/object-photos/v1/`을 유지한다. **manifest 형식은 version 2**이며 `sourceDimensions`와 선택적인 `crop`을 추가했다. 기존 v1 데이터 팩 형식과는 별개인 사진 manifest다.
- hero는 긴 변 최대 960px, thumb는 최대 160px, 전체 사진 예산은 15,000,000 bytes다. 확대하지 않고 선택한 관측 사각형을 contain 방식으로 축소해 WebP로 변환한다. 원본의 저해상도와 관측 노이즈를 감추기 위한 AI 보정은 없다.
- 2MASS 150개는 사진 밖의 큰 제목·기관 로고가 있는 편집 프레임만 제외했다. 밝은 천체 중심만 감지하는 자동 후보를 그대로 쓰지 않았다. 전체 원본 연락 시트를 확인하고, 어두운 성단·넓은 별밭·삽입 관측 사진 등은 원본 픽셀의 행·열 경계와 대조해 사각형을 수정했다.
- 베텔게우스는 여러 설명 요소가 붙은 원본에서 **전체 자외선 관측 패널**을 선택했다. 좌표는 원본 픽셀의 `left=123, top=28, width=980, height=980`이고 `reason=observation-panel`이다. 남은 NASA/STScI 13개는 원본 전체를 사용한다.
- 모든 선택 좌표는 원본 디코드 크기 안에 있는 정수다. 2MASS의 이유는 `editorial-frame`이다. M64는 관측 배경이 원본 좌우 끝까지 이어져 폭 443px 전체를 유지했다. 실제 관측 영역 위에 겹친 얇은 원본 세로선 두 개는 제거하지 않고 가공 설명에 밝혔다.
- M42/M43, M45, M53, M67, NGC104 등은 어두운 외곽 별밭까지 보존했다. M87 제트 및 NGC1097 중심 고리의 원본 확대 삽입 사진과 연결선도 과학적 설명 요소이므로 유지하고 캡션에 명시했다.
- 원래 색과 파장 배정을 바꾸지 않는다. 야간 보호는 파일 자체를 변형하지 않는 적색 표시 필터이며, 사용자가 원래 색을 선택하면 해제된다. 이 표시 방식도 각 가공 내역에 기록한다.

## 관측 자료 해석

대부분의 2MASS 사진은 J(1.2µm)·H(1.6µm)·Ks(2.2µm) 근적외선 관측을 파랑·초록·빨강에 배정했다. 맨눈이나 접안렌즈의 자연색과 다르며, 성운이 약하게 보이거나 수많은 별이 강조될 수 있다. NGC5139 원본은 회색조에 가까워 RGB 배정을 단정하는 공통 문구를 쓰지 않는다.

M42/M43과 안테나은하 쌍은 두 천체를 함께 담은 관측 영역임을 명시한다. M102는 이 앱 카탈로그가 NGC5866으로 연결하되 역사적 식별 논의와 원출처의 물음표를 설명한다. 시리우스의 십자와 고리는 망원경 회절이며 별 표면의 모양이 아니다. 베텔게우스는 자외선 대기, 태양은 극자외선, 금성은 구름의 대비 강조 합성, 달은 보라색·근적외선 합성임을 각각 안내한다.

모든 사진은 과거의 관측이다. 현재 시간과 위치의 실시간 하늘, 맨눈으로 보이는 색·밝기·크기를 뜻하지 않는다.

## 전체 감사 자료와 재현

**164개 전체 출처·크레딧·정책 링크·확인일·한영 캡션·가공·원본 크기·선택 좌표·입력/출력 SHA-256은 [공개 manifest](../public/object-photos/v1/manifest.json)에 있다.** 같은 데이터가 `src/catalog/objectPhotos.ts`에서 UI에 전달된다. 문서의 별도 수작업 표와 실제 파일 해시가 갈라지지 않도록 manifest를 기준으로 삼는다.

각 WebP의 XMP에는 천체 ID, 원출처·입력 URL, 전체 크레딧, 라이선스·권리 정책, 권리 판단, 확인일, 원본 SHA-256, 원본 크기, crop, 영어 캡션·가공 내역을 내장한다. 출력 파일 자신의 해시는 자기 자신 안에 내장할 수 없으므로 manifest에 기록한다. 같은 원본을 공유해도 천체 ID가 다른 파일에는 별도 XMP와 별도 경로·해시가 있다.

```sh
node scripts/data/prepare-object-photos.mjs --offline-inputs --prune
node scripts/data/prepare-object-photos.mjs --check
pnpm exec vitest run tests/unit/objectPhotos.test.ts tests/unit/objectPhotoUi.test.tsx
```

manifest가 검토된 입력이다. 변환기는 `artifacts/object-photos-research/originals-v2/` 또는 사전 수급 캐시에서 URL 해시로 원본을 찾고 SHA-256을 비교한다. `--offline-inputs`는 캐시가 없으면 중단한다. 일반 실행은 공식 URL 다운로드를 허용하되 기존 원본 해시가 바뀌면 중단한다. 확인 날짜나 권리 판단을 자동 갱신하지 않는다. `--check`는 네트워크 없이 전체 파일·XMP·기하·용량·미사용 자산을 검사한다. `--prune`은 고정 사진 폴더의 미사용 WebP만 연구 폴더에 사본을 남긴 뒤 제거한다.

이번 원본 경계 검토는 `artifacts/qa-build15/crop-analysis/approved-crops.json`, 수동 예외와 최종 164개 연락 시트는 같은 QA 폴더의 `crop-analysis/` 및 `photo-contact-final/`에 남겼다. 제품에 필요한 좌표·출처·해시는 ignored 연구 폴더에 의존하지 않고 공개 manifest와 XMP에 보존한다. 네이티브 번들, 서비스 워커 캐시와 실제 배포 UI는 릴리스 통합 검사에서 별도로 확인한다.

최종 사진 전수 무결성 검사와 대상 ESLint, 카탈로그·UI 단위 7개가 통과했다. 연락 시트 01~~05는 담당 에이전트가, 06~~09 및 별도 경계 예외 6개는 루트가 직접 확인했다. 편집용 제목·로고 잔여나 관측 영역 누락이 없는 것을 승인했으며, NGC1097의 삽입 사진과 IC443의 원본 선 표시는 보존했다.
