# 휴대폰에서 별관찰 앱 사용하기

현재 버전은 **0.1.0-beta.3 / build8**이다. **Android APK 다운로드와 iPhone 웹앱 업데이트를 이용할 수 있다.** 커밋 `e17373169c2475183f424be81031fb28f7fc939c`의 typecheck·lint·데이터 검증, 단위 433개와 브라우저 고유 시나리오 48개가 통과했다. 개인 APK 서명·다운로드, unsigned AAB 구조/내용과 공개 PWA를 확인했다. 로컬 Android release/lint와 새 모바일 CI 전체가 성공했다. CI에서는 Android release/lint·API36 오프라인 실제 WebView 계측과 iOS 무서명 컴파일을 통과했다. Google Play/App Store 공개 출시는 아직 완료되지 않았으며, 현재 체험판과 웹앱은 전 기능 무료다.

## beta.3에서 달라지는 사용 방법

- **현재 위치 자동 사용**이 기본이다. 실행하거나 앱으로 돌아올 때 GPS를 한 번 갱신하고, 처음에는 기기의 위치 권한을 요청할 수 있다. 거부하면 자동으로 계속 묻지 않으며 기존 좌표나 수동 관측지로 사용할 수 있다. 설정 → 관측지에서 자동 사용을 끄거나 저장한 관측지를 선택하면 그 선택을 유지한다. 이전 버전에 직접 지정한 기본 관측지도 보존한다.
- 하늘 화면은 방향 센서를 자동 연결한다. iPhone 최초 동작·방향 권한은 화면의 **휴대폰 방향으로 보기** 버튼을 한 번 눌러 승인한다. 이후 화면 재진입·앱 복귀 때 연결을 다시 시도한다. 센서를 직접 끄면 다음 실행에도 꺼진 선택을 유지한다. 나침반 방향을 확인하기 전에는 잘못된 방향으로 하늘을 돌리지 않는다.
- 별자리 **연결선과 경계선은 흰색**으로 더 선명하게 표시한다. 이 두 선은 적색 야간 모드에서도 흰색이고 다른 야간 레이어는 적색을 유지한다. 은하수는 밝기와 청보라·청록·먼지 결을 개선했다. 대기 효과가 켜져 있으면 낮/박명에 흐려지며, 낮에도 지도로 보고 싶으면 하늘 설정에서 대기 효과를 끈다.
- 위쪽은 관측지·설정과 작은 센서 버튼, 아래쪽은 작은 반투명 시각 표시와 5개 탭으로 정리했다. 시각을 눌러 날짜·시간 슬라이더·배속을 펼친다. 시간을 옮긴 동안에는 접어도 **시간 이동 중**과 **지금** 버튼이 남는다.
- 왼쪽 **하늘 설정**에서 **원형 하늘**, **별길 가이드**, **실제 하늘처럼**을 찾는다. 원형 하늘은 180° 반구 보기이며 손가락으로 돌려 다른 방향을 탐색할 수 있다. 목표 안내는 센서 도움말 아래에 놓인다. 글자 확대 시 탭·상태 바와 콘텐츠 여백도 함께 늘어난다.

위 내용은 build8 소스에 반영한 동작이다. 휴대폰에서 사용하기 전 아래 버전 확인과 실기기 점검을 진행한다.

## 안드로이드: 직접 설치용 APK

1. 휴대폰에서 [beta.3 / build8 APK 다운로드](https://github.com/JunhyoungPark-NOBEL/skylog/releases/download/v0.1.0-beta.3-build8/skylog-0.1.0-beta.3-build8-local-test.apk)를 연다. 또는 PC 전달 폴더의 같은 APK를 USB 등으로 휴대폰 Download 폴더에 옮긴다. PC에서는 APK를 실행하지 않는다.
2. 휴대폰의 내 파일/Files에서 APK를 열고 설치한다. 설치 출처 허용을 요청하면 이 APK를 연 앱에 대해서만 허용하고, 설치 후 다시 해제할 수 있다.
3. 앱 목록에서 **별관찰해쌀뚜**를 연다. Android 7 이상과 최신 Android System WebView/Chrome을 권장한다. 하늘·학습 자료는 설치 파일에 들어 있다. 날씨 갱신에는 인터넷이 필요하다.
4. 설치 후 아래 실기기 확인을 진행한다.

직접 설치 체험판은 release 모드 앱을 이 PC의 개인 체험용 키로 서명한 것으로 계측 테스트 실행용 APK가 아니다. build8과 build7 APK의 인증서를 직접 비교해 일치를 확인했다. build5~7에서 사용한 같은 개인 키와 더 큰 versionCode8이므로 **기존 앱을 삭제하지 않고 업데이트 설치**한다.

별 → 자세히 화면에서 손잡이뿐 아니라 본문·제목·버튼 행을 위아래로 쓸어 조작할 수 있다. 반쯤 열린 창을 위로 쓸면 펼쳐지고, 펼친 상태에서는 내용을 스크롤한다. 내용 맨 위에서 새로 아래로 당기면 접히고, 접힌 상태에서 다시 아래로 당기면 닫힌다. 버튼은 짧게 탭하면 실행된다.

하늘 화면에서 두 손가락을 모아 축소하거나 **원형 하늘**을 눌러 반구 전체를 본다. beta.3에서는 원형 하늘 버튼이 **하늘 설정** 안으로 이동한다. 별길 가이드의 **밤하늘에서 바로 찾기**는 나침반의 대략 방향으로 시작한다. 나침반을 사용할 수 없으면 목표 주변 하늘이 표시된다. 좁은 망원경 시야에 더 정확히 맞출 때만 **별로 더 정밀하게 맞추기 · 선택**을 사용한다. 이는 사진으로 별을 자동 인식하는 기능이 아니다.

**이미 같은 앱이 다른 서명으로 설치돼 있거나, 나중에 Play 설치판으로 옮길 때:** 기존 앱의 설정에서 JSON 백업을 내보내고 파일이 저장됐는지 확인한다. 서명이 다르면 덮어쓰기 설치가 되지 않는다. 백업 후에만 기존 앱 삭제 → 새 앱 설치 → JSON 가져오기 → 기록 수·사진·학습 진도 대조를 한다. 삭제 전 원본 기록을 꼭 보관한다.

`.aab`는 Play 제출용이고 휴대폰에서 직접 열어 설치할 수 없다. 현재 PC의 기존 업로드 키 복원이 끝나지 않았다면 `unsigned.aab`를 Play에 제출하지 않는다.

## 아이폰: 지금 홈 화면에 설치

APK는 Android 설치 파일이므로 iPhone에서 실행할 수 없다. 아래 Safari 웹앱 또는 별도 iOS 앱을 사용한다. **beta.3 웹앱 배포와 공개 버전·서비스 워커·작은 UI·원형 하늘·새로고침을 확인**했다. 자동 브라우저 검사에서 JS 오류는 없었으며 실제 iPhone의 센서·성능은 아래 체크리스트로 확인한다. 주소와 기존 홈 화면 아이콘을 그대로 사용한다.

1. 최신 iOS의 **Safari**에서 [별관찰 앱](https://junhyoungpark-nobel.github.io/skylog/)을 연다. 현재 UI는 iOS 16.4 이상을 권장한다.
2. **공유 → 홈 화면에 추가**를 선택한다. ‘웹 앱으로 열기’ 항목이 보이면 켜고 **추가**한다.
3. 홈 화면의 **별관찰** 아이콘으로 실행한다. 위치 권한을 허용하면 현재 관측지를 자동 갱신한다. 최초 **휴대폰 방향으로 보기** 버튼을 눌러 동작·방향 권한도 허용한다. 위치는 관측지 설정에서 자동 사용을 끄고 수동으로 입력할 수 있다.
4. 오프라인에서 쓸 이야기·배우기·별길 화면은 온라인 상태에서 한 번씩 연다. 기본 하늘 자료는 자동 저장되고, 깊은 별·이야기·학습은 사용한 자료가 저장된다. 네이티브 앱의 ‘첫 실행부터 모든 팩 포함’과 다르다.

Safari 웹앱과 TestFlight 네이티브 앱은 데이터 저장소가 별개다. 나중에 옮길 때 JSON 백업·가져오기를 사용한다.

기존 홈 화면 웹앱을 인터넷에 연결해 열고 잠시 기다린 다음 앱을 완전히 닫았다 다시 연다. **설정 → 맨 아래 버전 0.1.0-beta.3**인지 확인한다. 아직 이전 버전이면 Safari에서 새로고침한다. 화면 복귀/온라인 전환 때도 새 버전을 확인한다. 갱신을 위해 홈 화면 앱이나 Safari 웹사이트 데이터를 삭제하지 않는다. 관측 기록은 기존 저장소에 남는다.

## 아이폰: TestFlight 네이티브 앱

beta.3 / build8의 iOS arm64 무서명 컴파일은 [새 Mac CI의 Xcode 26 빌드에서 통과](https://github.com/JunhyoungPark-NOBEL/skylog/actions/runs/34195530826)했다. iPhone에 설치할 서명 IPA는 아직 없다. 필요한 것은 Apple Developer 팀, 확정된 Bundle ID, App Store Connect 앱 등록, 배포 인증서/프로비저닝, Xcode 26 이상이 설치된 Mac이다.

1. 최신 코드에서 `pnpm install --frozen-lockfile`, `pnpm mobile:sync`를 실행한다.
2. `ios/App/App.xcodeproj`를 Xcode로 열고 **Signing & Capabilities → Team**을 설정한다. Bundle ID는 현재 `io.github.junhyoungparknobel.skylog`이며 최초 등록 전에 소유자가 확정한다.
3. 배포 최소 iOS **16.4**, marketing **0.1.0**, 이번 Build **8**을 확인한다. 실제 App Store Connect에서 이미 사용한 번호가 있으면 그보다 커야 한다.
4. iOS 기기용 **Archive → Validate App → Distribute App → App Store Connect**로 업로드한다.
5. App Store Connect에서 본인을 내부 테스터로 추가하고, 아이폰의 TestFlight 앱에서 초대를 받아 설치한다. 외부 테스터는 베타 심사 조건이 추가된다.
6. 이번에 고친 센서 플러그인 등록을 반드시 실제 iPhone의 새 빌드에서 확인한다. 무서명 컴파일 성공은 실제 기기의 실행·센서 정확도 검증이 아니다.

## 먼저 해볼 실기기 확인

- [ ] 앱 종료 후 재실행, 한국어/English, 큰 글씨, 가로 화면.
- [ ] 설치본·홈 화면 PWA의 설정 버전이 `0.1.0-beta.3`인지 확인한다. Android는 위 build8 APK로 업데이트한다.
- [ ] 작은 반투명 탭·시간 표시 뒤로 하늘이 보이고, 200% 글자/안전 영역에서도 탭·시간 조절·목표 닫기 버튼이 겹치지 않는다. 시간 조절을 펼쳐 날짜·배속·지금 복귀를 확인한다.
- [ ] 별 → 자세히 → 본문에서 위로 쓸어 펼치기, 내용 스크롤, 맨 위에서 아래로 쓸어 접기/닫기. 즐겨찾기 탭·버튼에서 시작한 드래그·가로 버튼 행 확인.
- [ ] 하늘 설정 → 원형 하늘/핀치 축소 → 별 위치·방위·클릭 확인. 흰 별자리 연결·경계선, 밤하늘 은하수와 적색 야간 모드 확인. 대기 효과를 끄면 낮에도 은하수 지도가 표시되는지 확인.
- [ ] 별길 가이드 시작 → 나침반/방향 권한 → 별 정렬 없이 하늘과 방향 표시. iPhone은 잠시 평평하게 들고 나침반 방향이 잡히는지 확인. 금속에서 떨어진 곳에서도 대략 방향이 틀리면 기기/브라우저와 함께 보고.
- [ ] 첫 위치 허용 후 현재 좌표 반영, 앱 복귀 후 갱신. 위치 거부 시 반복 요청 없이 수동 관측지 사용. 자동 위치를 끄거나 관측지를 선택하고 재실행해도 선택 유지.
- [ ] 하늘 재진입/앱 복귀 때 센서 자동 연결, iPhone 최초 권한 버튼, 센서 직접 끈 뒤 재실행 시 꺼짐 유지. 폰 방향으로 하늘 보기와 화면 켜짐 유지.
- [ ] 센서 권한 안내·거부 도움말이 펼쳐져도 목표 이름·시간 이동·목표 해제가 가려지지 않는다.
- [ ] 별길에서 폰 윗변을 장비와 나란히 놓고 밝은 별 정렬. 좌우/위아래 방향과 10분 뒤 오차 확인.
- [ ] 화면 잠금/다른 앱 전환 뒤 자동 방향을 새로 잡고, 선택 정밀 모드에서는 다시 별 정렬하도록 안내.
- [ ] 관측 기록에 사진·메모 저장 → 퀴즈 → 앱 재실행 후 보존.
- [ ] JSON 내보내기 → 별도 환경에서 가져오기 후 기록·사진·학습 진도 일치.
- [ ] Android APK는 비행기 모드 첫 실행에서 하늘·깊은 별·코스·이야기·퀴즈 확인. iPhone 웹앱은 먼저 온라인에서 자료를 연 다음 오프라인 확인.
