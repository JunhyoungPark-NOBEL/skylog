# 업적 모음과 이야기 도해

2026-09-11 변경. 업적 데이터 팩 48개와 ID·달성 조건·보상 판정은 보존한다. 분류는 화면에서만 적용하며 별도 저장이나 이관을 만들지 않는다.

| 분류        | 기존 활성 업적 수 | 내용                                                |
| ----------- | ----------------: | --------------------------------------------------- |
| 하늘 발견   |                11 | 첫 관측, 천체 수, 별자리, 계절 모양                 |
| 깊은 하늘   |                 8 | 메시에·콜드웰 관측                                  |
| 관측 기록   |                 9 | 관측한 밤, 메모, 스케치, 사진                       |
| 퀴즈·이야기 |                11 | 연속 정답, 이해한 문항, 단계 통과·만점, 읽은 이야기 |
| 관측 실전   |                 9 | 미션, 정렬, 스타호핑                                |

전체 달성/전체 개수와 분류별 달성/전체 개수를 함께 표시한다. 목록은 항상 가로 3칸이며 작은 단색 도장·짧은 이름·진도만 보인다. 잠금과 획득은 자물쇠/체크 및 텍스트로 구분한다. 배지를 누르면 기존 이름·정확한 달성 조건·기존 난이도·상세 진도가 열린다. 영어의 긴 constellation 표기는 목록에서만 `constell.`로 줄이고 상세에는 전체 이름을 쓴다.

‘모은 업적만 보기’는 달성한 카드와 해당 분류만 표시한다. 전체 분모와 표시 중인 분류의 분모는 그대로다. 모은 것이 없으면 빈 상태 안내 한 번만 보인다. 비활성·알 수 없는 과거 ID는 집계에서 제외하며 오래 캐시된 v1 18개 팩에서도 실제 개수만 센다.

상세는 native dialog로 배경 조작을 막는다. 닫기와 Escape 후 원래 카드로 초점이 돌아오며 Tab은 닫기 버튼에 머문다. 개발 StrictMode의 늦은 close 이벤트가 다시 열린 상세를 없애지 않도록 열린 상태를 확인한다. 분류별 도장은 SVG/currentColor로 그려 야간 적색을 따른다.

이야기 ‘하늘 도해’는 실제 좌표·연결 구조·별 크기·사진/출처를 그대로 두고 연결선만 진하게 만들었다. 100×100 viewBox에서 썸네일 선폭 2.2, 상세 1.05, 불투명도 0.94, 둥근 끝점이며 일반·야간 테마의 글자색을 그대로 사용한다. 별자리 기하가 목록과 상세에서 일치하는지 검사한다.

검증: 관련 단위 5파일/22개 통과, 별도 dev 4177의 모바일 Chromium 3개 통과(360px, 영어 125%, 빈 상태, 총계/분류별 집계, 상세 조건, 그림 클릭 유지, Tab/Escape/닫기 초점 복귀, 관측 중복·새로고침, 도해 선·좌표 일치·야간). 화면 캡처는 `artifacts/qa-build23/achievements/`에 보관한다. Native top layer의 실제 조작은 브라우저 검사이며 jsdom의 대체 구현을 근거로 단정하지 않는다. 통합 정적 빌드·실기기 검증은 최종 릴리스 절차에서 별도로 확인한다.

영어 125%에서 48개 짧은 이름 전부 두 줄 이내이며 각 카드의 가로 넘침은 0이다(`names-en-125.json`). 계절 모양도 네 종류를 서로 다른 이름으로 표시한다. 초기 StrictMode 상세 소멸·Tab 초점 이탈과 영어 단어 잘림을 수정했고 최초 로그/trace는 덮어쓰지 않고 보존했다.
