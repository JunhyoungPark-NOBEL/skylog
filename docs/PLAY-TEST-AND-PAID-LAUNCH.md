## 1. 내부 테스트 등록

1. Play Console에서 이 앱 → 테스트 및 출시 → 테스트 → 내부 테스트 → 테스터.
2. 본인 포함 실제 Android 사용자의 Google 계정 이메일을 목록에 추가한다. 피드백 이메일은 `tony030214@gmail.com`.
3. 새 버전을 만들고 이번 빌드의 **play-signed.aab**를 올린다. APK/소스 ZIP/서명키는 업로드하지 않는다. 패키지 `io.github.junhyoungparknobel.skylog`를 유지하고 이미 올린 버전보다 큰 versionCode를 사용한다.
4. 미리보기와 오류를 확인한 뒤 내부 테스트로 출시한다. Console이 제공하는 참여 링크에서 각 테스터가 자신의 Google 계정으로 참여하고 Play에서 설치한다.
5. 기존 개인 APK와 Play가 설치하는 앱은 서명 인증서가 다를 수 있다. 업데이트가 거부되면 먼저 앱에서 기록·사진 백업과 복원을 확인한다. 데이터를 잃는 앱 삭제를 첫 해결책으로 사용하지 않는다.

내부 테스트 자체와 인앱결제 테스트는 별개다. **일반 앱 체험에는 라이선스 테스터 등록이 필요하지 않다.** 결제를 검증할 계정은 개발자 계정의 라이선스 테스터 목록에도 따로 등록한다. 판매 가능한 빌드에서는 내부 테스터에게도 실제 금액이 청구될 수 있으므로 Google 테스트 결제 수단과 테스트 구매 표시를 확인한다. 라이선스 등록은 본인·여자친구에게 영구 Plus를 부여하는 절차가 아니다. [테스트 트랙 공식 안내](https://support.google.com/googleplay/android-developer/answer/9845334?hl=en), [라이선스 및 결제 테스트 공식 안내](https://developer.android.com/google/play/billing/test)

## 3. 비공개 테스트

1. 개인정보처리방침, 앱 접근/심사 계정, 콘텐츠 등급/연령, 데이터 보안, 광고 없음, 스토어 이미지와 문구를 실제 빌드와 맞춘다.
2. 비공개 테스트 트랙에서 국가·테스터 목록·버전을 설정하고 검토를 위해 보낸다.
3. 참여 링크를 안내하고 각 테스터의 실제 참여를 확인한다. 내부 테스트 참여자는 내부에서 나간 뒤 비공개에 새로 참여해야 해당 트랙을 받을 수 있다.
4. 최소12명의 참여가14일 연속 유지되도록 확인하며 앱을 실제 사용한 피드백을 수집한다. 업데이트해 오류를 고쳐도 테스트를 계속한다.
5. Console이 신청 요건을 충족했다고 표시하면 프로덕션 접근을 신청한다. 참여도·피드백·수정 내역·출시 판단을 사실대로 적는다. 추가 테스트가 요구될 수 있다.

피드백 기록 양식: `날짜 / 앱 버전 / 기기·OS / 사용 기능 / 재현 방법 / 불편한 점 / 수정 내역 / 재확인`. 사진/이메일 등 개인 정보를 공개 저장소에 넣지 않는다. 참여자 모집이나 메시지 발송은 이번 코드 작업으로 자동 수행하지 않았다.

- 앱 설치 가격: **무료**. 앱 내부 상품: **Skyard Plus**, 비소비성1회 구매. 상품ID `skyard_plus_lifetime`, 구매 옵션 `buy`, 한국 가격 **₩9,900**.
- 상품 설명: `난이도 2·3 심화 퀴즈, 역사 천체물리 문제와 단계별 힌트, 망원경 학습·스타 호핑 코스를 한 번 구매로 이용합니다.`

- 난이도 1 퀴즈와 맨눈·쌍안경 코스, 그 무료 코스에 지정된 확인 문제는 무료로 유지한다. 하늘 지도·망원경 시야원 등 기본 관측 도구·기록·백업·기존 획득 보상도 구매와 무관하다.
- 현재 코드는 **preview**. 결제 서버 API를 조회하지 않으며 구매·복원도 시작하지 않는다. 상품 등록과 결제 서버 배포·자격 증명·환불 재검증·일반 로그인·심사 접근을 준비한 후, 라이선스 테스터 대상 별도 검증 환경에서만 서버 판매 플래그와 `live` 빌드를 먼저 켠다. 테스트 구매 허용 설정과 Google 테스트 수단으로 검증한 뒤 일반 판매를 활성화한다. 지금 베타 파일을 올린다고 판매가 자동 개통되지는 않는다.

## 정식 공개 전에 남은 필수 준비

일반 이메일 가입용 SMTP, 심사팀이 추가 메일 인증 없이 모든 제한 기능을 검토할 수 있는 접근 수단, 운영 담당자와 신고 처리, 삭제 요청 처리·보관 안내를 완료해야 한다. 현재 앱의 구매 데이터 수집이 실제 활성화되면 개인정보 안내와 Play 데이터 보안의 구매 내역/계정 관리 목적도 함께 갱신한다.

날씨 기능이 사용하는 Open-Meteo 무료 API는 비상업용이다. 유료 상품을 파는 앱으로 전환하기 전에 상업용 계약/적합한 공급자와 키를 서버에서 관리하는 경로를 마련해야 한다. API 데이터의 CC BY 출처 표시만으로 서비스의 상업 이용 계약을 대신하지 않는다. 이번 작업에서 유료 날씨 계약을 구매하지 않았다. [Open-Meteo 공식 요금·상업 이용 조건](https://open-meteo.com/en/pricing)

이 안내와 자동 테스트 통과는 실제 휴대폰 관측, Play 구매/환불, 일반 메일 왕복, Apple 심사 또는12명14일 테스트의 완료 증거가 아니다. 각 항목의 실제 결과를 위 표에 남긴 후 정식 출시한다.
