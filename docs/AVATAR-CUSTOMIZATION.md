# 아바타 꾸미기 확장 · beta.8 / build13

2026-09-09. 집 컴퓨터가 올린 main `f5cf178`(beta.7/build12)을 fetch한 뒤 새 작업을 시작했다. 이전 마당·잔디밭 풍경·천문 달력·커뮤니티와 사용자의 관측·학습 기록을 보존한다.

## 사용 방법

배우기의 내 마당 → 아바타에서 얼굴·머리·옷·소품을 고른다. 큰 미리보기와 각 선택의 그림을 보고 **이 모습 적용**을 누르면 마당에 반영된다. 취소·뒤로·다른 화면 이동은 적용하지 않은 미리보기를 버린다. ‘새 코디 추천’은 보유한 선택만 조합하고 ‘한 단계 되돌리기’로 이전 모습을 복원한다.

내 코디 보관함에 이름을 붙여 세 가지 모습을 저장할 수 있다. 코디 보관은 현재 마당의 아바타를 바꾸지 않는다. ‘꺼내 입어보기’ 후 적용하며, 보관한 코디를 교체하거나 한 칸을 비울 수도 있다. 마당 이름은 내 마당 홈에서 별도로 저장한다.

총 **39개 선택 중 기본 33개는 즉시 무료**, 나머지 6개도 업적으로 무료 획득한다. 기존 비니·헬멧·색 선택은 유지한다. 새 머리 모양·색·표정·옷·소품이 없는 예전 저장값에는 기존 모습에 맞는 기본값을 넣는다.

| 보상        | 획득 조건                |
| ----------- | ------------------------ |
| 작은 쌍안경 | 첫 관측 기록             |
| 관측 수첩   | 첫 스케치 기록           |
| 별밤 등불   | 서로 다른 3일 관측       |
| 별빛 지팡이 | 서로 다른 천체 25개 관측 |
| 탐험 우주복 | 퀴즈 스테이지 5개 완료   |
| 별빛 모자   | 이야기 10편 읽기         |

기존 업적 판정과 진행률을 그대로 이용하며, 이미 조건을 달성한 사용자도 내 마당을 열면 보상을 받는다. 한번 얻은 보상은 기록을 나중에 지워도 유지된다. 기존 마당 장식 12종은 그대로다. 색·표정·의상은 꾸미기 표현이며 실제 장비 설정을 바꾸지 않는다.

## 저장·그림·접근성

- `personal.profile`의 기존 이름·배치·색·모자를 유지하고 새 아바타 필드를 추가한다. `personal.looks`에는 세 칸의 코디, `avatar.reward:<category>:<value>`에는 획득 이력을 저장한다. DB 스키마와 천문/학습 팩 버전은 바꾸지 않는다.
- 이름·마당 배치·아바타·코디는 트랜잭션 안에서 최신 값을 읽고 필요한 부분만 저장한다. 저장 후 화면 데이터가 갱신될 때까지 다음 저장을 막는다. 실패 시 미리보기를 남기고 다시 시도할 수 있다.
- 기존 JSON 백업과 수동 계정 백업에 코디·보상이 함께 포함된다. 알 수 없는 선택·손상 값·미획득 보상은 정규화한다. 로컬 보상은 결제 권한 검증 수단이 아니다.
- 기존 코드 기반 SVG를 확장했다. 머리·모자·표정·옷·소품을 구분하고 야간은 각 그림의 고유 필터로 적색 처리한다. 생성 이미지나 새 외부 에셋·패키지를 추가하지 않았다. 잔디밭 텍스처를 변경하지 않는다.
- 한영 문구, 키보드 버튼, 선택 상태와 잠금 조건의 접근 가능한 설명을 제공한다. 360px/영어 125%와 야간 색을 확인한다.

## 검증과 설치

최종 테스트·서명·배포 결과는 [STATUS](../plan/STATUS.md)와 [모바일 릴리스](MOBILE-RELEASE.md)에 기록한다. 자동 검사는 구형 아바타 조합·정규화·중복 보상·동시 저장·백업 복원·편집 적용/취소·코디 보관·언어/야간을 다룬다. 실제 휴대폰 설치·센서 체감은 사용자가 확인한다.

Android는 기존 개인 테스트 키로 서명한 build13 APK를 사용한다. 설치 전 설정에서 JSON 백업을 보관하고, 기존 앱을 삭제하지 않고 업데이트한다. iPhone은 [웹앱](https://junhyoungpark-nobel.github.io/skylog/)을 Safari로 열어 공유 → 홈 화면에 추가한다. APK는 iPhone에서 실행되지 않는다. 설정의 버전은 `0.1.0-beta.8`이다.

폰에서는 기존 관측·장비·퀴즈 진도, 아바타 적용/취소와 코디 재실행 보존, 업적 보상, 야간·스크롤을 확인한다. 스토어 정식 출시·Apple 서명/TestFlight·일반 가입 메일/실계정 운영 개통은 별도다.
