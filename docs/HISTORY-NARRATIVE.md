## 저장과 접근

- 기존 30개 계산·판단과 60개 개념 질문의 ID·정답·수치·허용오차·힌트·저장 형식은 변경하지 않는다. 데이터 팩 버전도 유지한다.
- 각 장의 계산·판단을 한 번 이상 제출하면 결말을 읽을 수 있다. 오답에도 해설을 제공하므로 이야기 감상을 막지 않되, 끝 화면에 실제 정답 수와 복습할 장을 표시한다. 장 이동·초안·메모·결말 열기로 점수나 보상을 만들지 않는다.
- 마지막 장만 푼 경우 ‘남은 장면 이어가기’가 첫 미제출 장으로 안내한다. 모든 장에 제출 기록이 있으면 ‘이야기 마치기’를 표시한다. 기존 버전에서 쌓인 기록도 재사용한다.
- 결말에서 첫 장 또는 특정 장으로 돌아가도 기존 풀이·힌트 기록을 지우지 않는다. 장별 미저장 초안 보존과 DB 조회 실패 시 복구는 기존 경로를 유지한다.
- 용어 홀드는 450ms, 짧은 탭·스크롤 취소 및 키보드 접근을 유지한다. 수식 변수 이탤릭·아래첨자 직립체, 계산 도해, PWA 캐시 동작도 유지한다.
- Plus의 베타 미리보기 상태와 가격 계획은 이번 서사 개편에서 변경하지 않는다.

## 사실 확인과 검증

[역사 출처와 계산 제한](HISTORY-QUESTS-SOURCES.md)을 따른다. 새로운 장면은 원전 대화나 일기라고 제시하지 않으며, 독자가 교육용 관측 자료를 검토하는 서술이다. 페인의 두 모형, 현대 쌍성 계산과 거리 보정, 별도의 허블 계수, 구대칭·국소 평면·이상화된 백색왜성 같은 가정의 전환을 장면에서 구분한다.

단위 검사는 열 이야기의 양 언어·90장면·문항 연결과 결말 개방 조건을 확인한다. 실제 Chromium은 열 이야기의 모바일 도입/장면, 9단계 왕복, 오답과 결말의 구분, 초안·재실행 보존, 용어 홀드, 야간 영어 125% 글자, 서비스워커 오프라인 풀이를 확인한다. 실제 안드로이드·아이폰의 손가락 조작은 사용자 확인 항목이다.
