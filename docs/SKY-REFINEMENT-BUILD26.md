# 확대 안정화와 하늘 중심 안내 — beta.20 / build26

2026-09-13. 기준은 연구실 업데이트를 반영한 beta.19/build25(`6bf4e5e`)다. 요청 기기는 Galaxy S24+ Android 설치 앱이며, 추가 손떨림 피드백은 웹에서 확인한 사용 경험이다.

## 바뀐 사용 흐름

- 하늘 위쪽에 설정·하늘 설정·시간을 모았다. 카메라 켜기와 밝기·시야 조절은 왼쪽 위 설정 안에 있다. 아래에는 GPS 센서 버튼을 두며 손으로 둘러보기 중 별도의 복귀 패널을 띄우지 않는다. 기존 5초 자동 복귀는 계속 제거된 상태다.
- GPS 센서라는 버튼 이름을 사용하되 설정에서 위치는 GPS, 방향은 나침반·자이로를 사용한다고 설명한다. GPS만으로 방향을 추정한다고 안내하지 않는다. 자동 나침반·자이로와 밝은 별 정렬, 카메라 권한/해제는 유지한다.
- 망원경으로 찾기를 누르면 메인 하늘에 목표와 파인더·접안 시야 원이 나타난다. 별도 큰 화살표 페이지는 사용하지 않는다. 화면 밖 목표의 방향은 하늘 가장자리 화살표로 표시한다. 장비·보조 시야 차트·GoTo 좌표 복사는 더보기 안에 있다.
- 경통과 평행하게 둔 휴대폰의 머리 방향(물리 +Y)을 추적한다. 후면 카메라 방향과 구별하며 기존 한 별/두 별 정렬과 자이로 보정을 유지한다. 실제 안내 중에는 시간 이동을 잠근다. 원의 크기는 장비 설정값에 따라 달라지며 시작 예시는 실제 장비 사양의 확인을 대신하지 않는다.
- 스타호핑은 배우기 → 코스 → 망원경 관측 → 스타호핑 입문으로 모았다. 한 번에 한 구간을 보고, 두 끝별의 이름·주변 밝은 별·실제 파인더 시야를 비교한다. 큰 별길 지도와 길을 놓쳤을 때 복귀 안내를 제공한다. 하늘 지도 왕복·새로고침 때 현재 단계를 복원한다.

## 안정화 원리와 검증 범위

기존 필터는 확대해도 정지 시 평활 강도가 거의 같았고, 왕복 손떨림의 순간 속도가 빠른 움직임으로 해석될 수 있었다. 새 필터는 쿼터니언을 유지하며 시야각과 220ms 동안의 순변위/총 이동량을 함께 사용한다. 확대해 멈추면 강하게 안정화하고, 한 방향으로 움직이면 지연을 줄인다. 줌 변경으로 필터를 초기화하지 않으며 오래된 이벤트와 긴 수신 공백을 처리한다.

[1€ 필터 저자 자료](https://gery.casiez.net/1euro/)의 속도에 따른 평활 원리를 참고한 별도 구현이다. 정식 1€ 알고리즘을 그대로 구현했다는 의미는 아니다.

30/60/90Hz, 3° 시야, 9Hz·4Hz 합성 왕복 입력에서 잔여 RMS가 원 입력의 15% 미만인 것을 단위 검사한다. 일정한 5°/s 이동의 추종 오차는 0.4° 이내, 큰 90° 이동은 150ms 이내에 2° 범위로 도달하는 것을 검사한다. **이 결과는 합성 입력 시험이며 S24+에서 측정한 손떨림 감소율이 아니다.** 물리 센서 정확도·기기별 지연·자이로 드리프트와 실제 접안 시야는 실기기 확인이 필요하다.

브라우저에서는 한 개의 메인 WebGL 캔버스, +Y 방향 대응, 시야 원의 실제 픽셀, 탭·핀치 유지/드래그 일시정지, 정렬·도착·코스 완료·업적·복원 경로를 확인한다. 보조 차트가 하단 탭에 가려진 문제를 발견해 하늘 위 보조 화면만 전역 탭 위에 올렸다. 독립 코스의 기존 렌더링과 학습 접근 검사는 유지한다.

별 ID·좌표·밝기는 저장소 카탈로그를 사용한다. 도해는 자체 FinderChart로 그리며 외부 차트 이미지·코드는 복사하지 않는다. 구간이 실제 파인더보다 넓으면 넓은 맥락도 안에 파인더 원을 따로 표시한다. 기존 코스 ID·획득한 진도/업적은 보존하고 새 단계 체크포인트는 세션 저장소에 둔다. 시뮬레이터 확인으로 실제 관측 업적을 주지 않는다.

경로의 관측 근거: Skyledge 관측 가이드 [M13](https://www.skyledge.net/Messier13-hop.htm), [M57](https://www.skyledge.net/Messier57-hop.htm), [M27](https://www.skyledge.net/Messier27-hop.htm), [M31](https://www.skyledge.net/Messier31-hop.htm), [M11](https://www.skyledge.net/Messier11-hop.htm), [NASA M42 설명](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-42/). 장비와 광해에 따라 보이는 정도는 달라진다.

## 실기기 확인

- [ ] S24+ 설치 앱과 Chrome: GPS 센서를 켜고 밝은 별을 3–10° 시야로 확대해 잠시 멈춘다. 미세 떨림과 움직이기 시작할 때 지연을 비교한다. 별 탭·핀치 때 추적이 계속되는지 확인한다.
- [ ] 손으로 드래그하면 수동으로 남으며 복귀 패널은 없다. 오른쪽 아래 GPS 센서 버튼으로 돌아온다. 상단 설정·하늘 설정·시간과 카메라 조작이 가리지 않는지 확인한다.
- [ ] 실제 밝은 별에 경통/휴대폰 머리를 나란히 맞춰 한 별 또는 두 별 정렬한다. 메인 하늘의 중심 원과 이동 방향을 확인한다. 접안 결과와 차이가 나면 장비 시야·정렬을 확인한다.
- [ ] M13/M31 등 현재 관측 가능한 코스에서 큰 별길 → 구간 확인 → 하늘 지도 → 돌아오기 → 완료를 진행한다. 이전 단계와 기록·업적이 보존되는지 확인한다.
