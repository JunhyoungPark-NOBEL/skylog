## 1. 목표

망원경(또는 삼각대 쌍안경)에 폰을 붙이고 밝은 별 1~2개로 정렬하면, 목표 천체까지 **"위로 12.3°, 오른쪽으로 5.1°"** 를 큰 화살표와 불스아이로 실시간 안내하고, 시야에 들어오면 파인더/접안렌즈에서 보일 별 배치를 시뮬레이션해 마지막 확인을 돕는다. 센서가 못 미치는 마지막 정밀도는 **스타 호핑 경로**로 사람이 채운다. 쌍안경(손으로 들 때)은 AR 화살표로 방향을 잡고 FOV 원으로 "이만큼 보일 것"을 미리 본다.

   - 계산기 카드: 선택 조합의 배율·실시야·한계등급(근사)·분해능(도스)·달 지름 대비 시야.

2. **FOV 원 오버레이** (`render/FovLayer.ts`, 하늘 화면)
   - 레이어 패널에서 켜는 원들: 쌍안경, 파인더, 접안렌즈(여러 개 동시). 원은 화면 중심(AR/센서 모드) 또는 선택 대상 중심(수동 모드)에 그리며, 각도 크기가 정확(FOV 변경에 따라 픽셀 크기 변함, 좁은 FOV에서 확인). 라벨: "10×50 6.5°", "25mm 2.6°".
   - 대상 상세 시트의 "이 장비로" 섹션에서 "시야에 맞춰 보기" → 하늘을 그 대상 중심·해당 FOV 원이 화면에 꽉 차게 이동.

3. **정렬 수학** (`astro/pointing.ts`, 순수 함수 + Vitest)
   - 모델: 세계 프레임 포인팅 `p = R_yaw(δ) · q_s · t_b`. `q_s`=센서 쿼터니언(기기→세계), `t_b`=기기 프레임에서의 경통 광축(미지 단위벡터), `δ`=세계 프레임 yaw 오프셋(나침반/자이로 기준점 오차).
   - **1-별 정렬**: δ는 T2 보정값(없으면 0), `t_b = q_s⁻¹ · R_yaw(δ)⁻¹ · d₁` (d₁ = 정렬 별의 apparent 방향 벡터, 정렬 시각 기준).
   - **2-별 정렬**: δ를 ±40° 범위에서 1차원 탐색(황금분할 또는 0.1° 격자 후 정밀화). 각 δ에 대해 `t_b = normalize(Σᵢ q_sᵢ⁻¹ R_yaw(δ)⁻¹ dᵢ)`, 잔차 = Σ angle(R_yaw(δ) q_sᵢ t_b, dᵢ). 최소 잔차의 (δ, t_b) 채택, 잔차(°)를 UI에 표시. 3번째 별은 검증용(잔차만 보고).
   - 정렬 후 **센서 소스는 상대(자이로) 우선**: `RelativeOrientationSensor`/`deviceorientation`(비-absolute). 금속 경통·마운트 근처에서 나침반은 신뢰하지 않는다. 드리프트 대응: "재정렬(지금 중앙에 있는 별)" 원탭 + 10분 경과/잔차 증가 시 안내 배지.
   - 안내 계산: `p → (alt_p, az_p)`, 목표 `(alt_t, az_t)`(apparent, 현재 시각), `Δaz = wrap180(az_t − az_p)`, `Δalt = alt_t − alt_p`, 각거리. 경위대: 그대로. **적도의**: 둘 다 시간각/적위로 변환(`HA = LST − RA`), `ΔHA`(시·분 및 도)와 `ΔDec`. 테스트 벡터: 알려진 q_s/δ/t_b로 합성한 별 2개에서 δ·t_b 복원 오차 < 0.05°, 노이즈 0.5° 추가 시 < 1°.
   - 정렬 세트 저장(장비·시각·δ·t_b·잔차) — 같은 밤에 폰을 떼지 않았다면 재사용.

4. **망원경 모드 UI** (`features/telescope/TelescopeMode.tsx`, 전체 화면, 가로/세로 모두)
   - 진입: 상세 시트 `망원경으로 찾기` 또는 하늘 화면의 망원경 버튼(목표 없으면 검색으로).
   - 상단: 목표 이름·종류·현재 고도/방위·"지금 보임/지평선 아래". 정렬 상태(별 이름·경과 시간·잔차).
   - 중앙 **불스아이**: 가로 `Δaz·cos(alt)`, 세로 `Δalt`, 링 = 20°/10°/파인더 FOV/접안렌즈 FOV(현재 접안렌즈 선택). 목표 점이 중심으로 오면 링 색이 바뀌고 피드백(Android 진동 패턴; iOS는 화면 테두리 플래시가 1차, 소리는 옵션 — 무음 스위치 때문).
   - 하단 **큰 화살표 2개 + 숫자**: "↑ 12.3°", "→ 5.1°"(경위대: 위/아래·왼쪽/오른쪽, 오른쪽=방위 증가=시계 방향). 적도의: "RA ← 4m 12s(서)", "Dec ↑ 3.2°". GoTo: 화살표 대신 좌표 카드(JNow RA/Dec, Alt/Az, 복사, "GoTo에 입력 후 '도착' 누르기").
   - 버튼(64px+): 정렬/재정렬, 뷰 전환(화살표 ↔ 파인더 뷰 ↔ 접안렌즈 뷰, 각거리에 따라 **자동 전환** 옵션), 목표 변경, 스타 호핑 보기, 종료. Wake Lock 자동. 야간 모드 강제 권장(진입 시 제안).
   - 정렬 마법사: ① 대상 추천 목록(고도 25~75°, 밝기순, 행성·달 포함 — **태양은 절대 제외**(태양 필터 확인 체크가 켜진 세션에서만 허용)) ② "접안렌즈 중앙에 놓고 탭" ③ (선택) 두 번째 별 ④ 잔차 표시·완료. 폰 홀더 안내 그림(텍스트)과 "정렬 후 폰을 만지지 마세요". T2의 보정 마법사를 재사용하되 망원경/쌍안경 모드에서는 이 제외 규칙이 강제된다.

5. **파인더/접안렌즈 뷰** (`render/EyepieceView.ts`)
   - 현재 포인팅(또는 목표) 중심, 선택 장비의 실시야를 원형 마스크로 렌더. 별은 `stars-deep` 팩(≤ 9등급; 이보다 어두운 별은 없음을 UI에 표기), DSO 심볼·라벨, 밝은 별 이름. **상 방향 적용**: 정립(그대로) / 도립(180° 회전) / 좌우반전(X 반전, 천정 프리즘 굴절망원경) / 상하좌우반전. 회전 각도는 지평 좌표 기준(경위대) — 적도의는 적도 좌표 기준 옵션.
   - 현재 위치와 목표가 같은 뷰에 들어오면 목표 마커 + "목표까지 0.8°". 뷰 위에 스와이프해 시야를 미리 둘러보기(포인팅과 분리 표시).

6. **스타 호핑** (`astro/starHop.ts` + `features/telescope/StarHop.tsx`)
   - 입력: 목표, 호핑 시야(기본 파인더 FOV, 없으면 쌍안경/최저배율 접안렌즈 FOV), 별 한계등급(파인더 6×30 ≈ 7.5, RDF ≈ 맨눈 LM, 쌍안경 ≈ 9), 시작 후보(목표에서 25° 이내 mag ≤ 3.0, 없으면 ≤ 4.0 — 가장 가깝고 밝은 것).
   - 알고리즘(탐욕 + 백트래킹 제한): 현재 위치에서 `0.8×FOV` 안의 별 중 목표까지 거리를 가장 줄이면서 **주변에서 가장 밝은(식별 가능한)** 별을 다음 홉으로. 목표가 `0.5×FOV` 안에 오면 종료. 최대 7홉, 실패 시 FOV 1.2배로 재시도. 각 홉에 방향(16방위 + "시야 n.n개 만큼")과 각거리.
   - 출력 UI: 단계 카드 목록(각 카드에 미니 차트 = 접안렌즈 뷰 축소, 이전·다음 홉 표시) + 하늘 화면에 경로 폴리라인 오버레이. "이 단계 완료" 체크로 진행. 상 방향이 반영된 차트.
   - 테스트: M13(η Her–ζ Her 사이), M57(β Lyr–γ Lyr 사이), M31(β And→μ And→ν And), M27(γ Sge에서), M11(λ Aql에서) — 합리적 홉 수(≤ 4)와 실제 관행과 유사한 경로가 나오는지 스냅샷 테스트.

7. **쌍안경 흐름** (`features/telescope/BinocularMode.tsx`)
   - 손으로 들 때: AR 모드 + T3 TargetGuide 화살표 + 화면 중앙에 쌍안경 FOV 원 + "이 방향으로 쌍안경을 드세요" + 시야 안 별 배치 미리보기(접안렌즈 뷰 재사용, 정립). 화면이 꺼지지 않게, 큰 글씨.
   - 삼각대 + 폰 클램프: 망원경 모드와 동일(장비=쌍안경, 정립).

8. **안전** (`features/telescope/SunGuard.ts`)
   - 태양 고도 > −6°이고 목표 또는 현재 포인팅이 태양 15° 이내면 **빨간 전면 경고**(망원경·쌍안경으로 태양을 보면 실명). 태양을 목표로 설정하려 하면 차단(태양 필터 사용 확인 체크박스로만 해제, 세션마다). 망원경 모드 첫 진입 시 1회 안전 안내.

## 4. 기술 사양 메모

- 상 방향 규칙(기본값, 사용자 덮어쓰기 가능): 굴절/슈미트카세그레인 + 천정 프리즘(90°) = **좌우반전(정립 상하)**; 굴절 직시·뉴턴식 = **도립(180°)**; RACI 파인더·레드닷·쌍안경 = **정립**; 직시 광학 파인더 = 도립. 실제로는 다이아고날 각도에 따라 회전이 더해지므로 "회전 미세 조정(±180°)" 슬라이더 제공.
- 불스아이의 가로축은 `Δaz·cos(alt_t)`(천정 근처에서 방위 변화가 과장되지 않게). 천정 ±5°에서는 방위 화살표를 숨기고 "천정 근처 — 고도만 조정" 표시.
- 정렬 시각과 안내 시각이 다르면 별의 alt/az가 움직인다: `d_i`는 정렬 시각의 apparent 방향으로 고정하고, 안내는 현재 시각의 목표를 쓰면 됨(모델은 세계 프레임이므로 정확).
- 폰이 경통에 고정된 상태에서 `q_s`는 화면 방향 변경 이벤트로 흔들릴 수 있음 → 망원경 모드에서는 `screen.orientation.lock` 시도(실패해도 무시) + 화면 방향 보정 값을 정렬 시점에 고정.
- 접안렌즈 뷰 렌더는 별도 `WebGLRenderTarget` 또는 두 번째 캔버스. 성능 예산 유지(깊은 팩 10만 별도 Points 1개).

- [ ] 시뮬레이터(T2)로 Playwright: 장비 프로필 생성(SV48P + 25mm) → 대상 M13 → 망원경 모드 → 2-별 정렬(시뮬레이터가 별 방향에 맞춘 q_s 주입) → 잔차 < 0.1° 표시 → 화살표가 0으로 수렴 → 자동으로 접안렌즈 뷰 전환 → 스타 호핑 카드 ≥ 2단계.
- [ ] FOV 원의 각도 크기 정확(FOV 10° 화면에서 6.5° 원의 픽셀 지름이 기대값 ±2%).
- [ ] 접안렌즈 뷰의 4가지 상 방향이 스크린샷으로 구분되고, 좌우반전에서 북두칠성 손잡이 방향이 거울상으로 보임.
- [ ] 태양 안전 경고가 낮 시간 시뮬레이션에서 발동.
- [ ] 쌍안경 흐름 스크린샷. 야간 모드 준수. typecheck/lint/test/build 통과. 태그 `task-5-done`(실기기 반영 후).

## 7. 실기기 테스트 체크리스트 (사용자에게 전달)

- [ ] 쌍안경 모드: AR 화살표로 달/행성을 찾고 쌍안경을 들었을 때 시야 안에 들어오는가, FOV 원과 실제 시야가 비슷한가
- [ ] (망원경 또는 삼각대 쌍안경 + 폰 홀더) 1-별 정렬 후 다른 밝은 별을 목표로 → 화살표 0에서 실제로 파인더 시야 안에 있는가(오차 °)
- [ ] 2-별 정렬 후 잔차 값, 10분 뒤 드리프트 정도(재정렬 없이 다른 별 목표)
- [ ] 접안렌즈 뷰의 상 방향이 실제 접안렌즈에서 본 것과 같은가(천정 프리즘 사용 시 좌우반전)
- [ ] 스타 호핑 카드로 M31/M13(계절에 맞는 것)을 실제로 찾아보기 — 홉 설명이 이해되는가
- [ ] 진동/소리 피드백, 큰 버튼 조작감, 화면 회전 시 안정성
