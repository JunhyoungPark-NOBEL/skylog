## 2. 범위

- In: `scripts/data/build-content.ts`, `validate-content.ts`, `public/data/content/v1/*.json`(+ `index.json`), `features/content/*`(뷰어, 오늘의 천체), 상세 시트 "스토리" 탭, 검색에 "스토리 있음" 표시, 전통 별자리/이름(A7, 데이터가 준비된 만큼만).

## 3. 요구사항

### MUST

1. **콘텐츠 스키마** (`src/content/schema.ts`, zod 등으로 런타임 검증 + 빌드 검증)

```ts
interface ContentEntry {
  id: ObjectId;                    // star:HIP91262, dso:M31, planet:saturn, moon, sun, const:Ori
  version: number;                 // 항목 단위 버전(수정 시 +1)
  title: { ko: string; en: string; alt?: string[] };   // "베가 (직녀성)", "Vega"
  oneLiner: { ko: string };        // ≤ 60자
  summary: { ko: string; en?: string };                 // 200~400자, 초보자용
  facts: { label: string; value: string; source?: string }[];  // 거리·등급·분광형·크기·나이 등 5~8개. 수치는 카탈로그 대조 대상
  story: { ko: string; cultures: string[]; sources: string[] }; // 300~600자: 신화·역사·명명 유래. 문화권 명시(그리스·로마/동아시아/한국/아랍/기타)
  koreanTradition?: { name?: string; asterism?: string; note: string; sources: string[] }; // 직녀성, 28수 소속 등(있을 때만)
  howToFind: { ko: string; season?: 'spring'|'summer'|'autumn'|'winter'|'any'; hopFrom?: ObjectId[] };  // 계절 enum은 T7 학습 스키마·G3 프롬프트와 동일(영문), 표시할 때 현지화
  observing: { nakedEye?: string; binoculars?: string; telescope?: string; bestMonths?: number[]; difficulty: 1|2|3|4|5 };
  funFacts?: string[];             // ≤ 3개
  safety?: string;                 // 태양 등
  sources: string[];               // 제목 + URL(위키백과 ko/en, NASA, ESA, IAU 등)
  meta: { generatedBy: 'gpt-5-pro'|'claude'|'human'; generatedAt: string; reviewedBy?: 'claude'|'human'; reviewedAt?: string; confidence: 'high'|'medium'|'low'; needsReview?: string[] };
}
```

2. **대상 목록** (`data-src/curated/content-targets.v1.csv`: id, priority 1~3, 이유 — **T0b에서 작성됨**, 여기서는 확인·보정만). 구성 120개:
   - 행성·달·태양(9): 수성·금성·화성·목성·토성·천왕성·해왕성·달·태양(안전 문구 필수).
   - 밝은 별(31): 시리우스·카노푸스·아르크투루스·베가·카펠라·리겔·프로키온·베텔게우스·알타이르·알데바란·안타레스·스피카·폴룩스·포말하우트·데네브·레굴루스·카스토르·북극성·미자르&알코르·알비레오·알골·알페라츠·미라·두베·알카이드·알니탁·알닐람·민타카·벨라트릭스·하말·코카브 — 한국 전통 이름이 있는 별(직녀성·견우성·북극성·삼태성 등)을 우선순위 1로.
   - 별자리(30): 황도 12 + 오리온·큰곰·작은곰·카시오페이아·백조·거문고·독수리·페가수스·안드로메다·페르세우스·마차부·큰개·작은개·헤르쿨레스·목동·용·고래·남십자(남반구 안내용).
   - DSO(50): M31·M32·M110·M33·M42·M43·M45·M44·M13·M92·M3·M5·M57·M27·M51·M81·M82·M101·M104·M8·M20·M17·M16·M22·M11·M6·M7·M35·M36·M37·M38·M41·M46·M47·M67·M15·M2·M39·M103·M4·M10·M12·M29·M34·M52·M78·이중성단(NGC 869/884)·NGC 7000(북아메리카)·NGC 457(ET 성단)·NGC 7009(토성 성운).

3. **생성 파이프라인**
   - 기본 경로: GPT Pro **G3** 프롬프트로 배치 생성(JSON 배열) → 사용자가 붙여넣기/파일 첨부 → `data-src/content-raw/batch-N.json`.
   - 대체 경로(G3 산출물 없을 때): 이 세션이 같은 스키마로 **우선순위 1 대상 20개**를 직접 작성(`generatedBy:'claude'`), 나머지는 G3에 위임한다고 보고.
   - 두 경로 모두 `validate-content.ts`를 통과해야 팩에 포함.

4. **검증 패스** (`scripts/data/validate-content.ts`, 실패 목록 출력)
   - 스키마 검증(필수 필드·길이·문화권 값·URL 형식).
   - **수치 대조**: facts의 거리(광년/AU)·등급·분광형·크기가 카탈로그(`stars-bright.v1.json`, `dso.v1.json`, 행성 상수)와 허용 오차 안인지 — 등급 ±0.3, 분광형 앞 두 글자 일치, 크기 ±30%, **별 거리 ±30%**(데네브·베텔게우스·리겔·안타레스처럼 히파르코스/가이아/문헌 값이 20~50% 다른 별이 많으므로 거리 불일치는 **경고**로만 취급하고 실패로 처리하지 않음), DSO 거리 ±40%(경고). 실패 항목은 `needsReview`에 기록, `confidence` 강등. G3에 "카탈로그 값과 다른 값을 쓰면 출처를 명시"를 요구했으므로 출처가 있는 편차는 통과.
   - 금칙: "정확히", "확실히" 같은 과장 표현, 출처 없는 story, 태양 항목에 안전 문구 없음, 다른 천체 설명 혼입(id와 title 불일치 검사: 카탈로그 이름과 title 매칭).
   - 세션(Claude)이 **각 항목을 읽고** 명백한 오류(신화 인물 혼동, 별자리 소속 오류, 계절 오류)를 수정하거나 `needsReview`에 남긴다. 수정 이력은 `data-src/content-raw/review-log.md`.

5. **팩 빌드** (`build-content.ts`)
   - 항목당 파일 `content/v1/<id-safe>.json`(지연 로드) + `content/v1/index.json`(id, title, oneLiner, difficulty, bestMonths, hasStory, version, 검색 표시용). 팩 매니페스트에 버전·항목 수·생성일.
   - 갱신 규칙: 항목 수정 시 `version+1`, 팩 버전(v1→v2)은 스키마 변경 때만. 서비스 워커 캐시는 index 변경 시 새 항목만 받는다.

6. **뷰어** (`features/content/StoryView.tsx`, 상세 시트 "스토리" 탭 + 전체 화면)
   - 섹션: 한 줄 요약 → 핵심 사실(표) → 이야기(문화권 태그) → 한국 전통(있으면) → 찾는 법("하늘에서 보기" 버튼 연동, hopFrom 별 링크) → 관측 팁(장비별 탭, 난이도 별표, 좋은 달) → 재미있는 사실 → 출처(링크, 외부 브라우저) → 메타(생성/검토, confidence 배지, "오류 신고" = 로컬 메모로 `needsReview` 추가·내보내기).
   - 글자 크기 조절, 야간 모드, 오프라인 캐시(첫 열람 후). 읽음 표시(`progress`에 저장, T7 학습과 연동).

7. **오늘의 천체** (`features/content/TodayCard.tsx`, "오늘 밤" 탭 상단·"배우기" 탭)
   - 선택 규칙: 오늘 밤 실제로 보이는(고도 ≥ 25°, 어두운 창 안) 콘텐츠 보유 대상 중, 미열람 우선 → 우선순위 → 날짜 기반 결정적 셔플(같은 날은 같은 카드). 카드: 제목·한 줄·"지금 남동 40°"·"스토리 읽기"·"하늘에서 보기".

8. **전통 이름/별자리(A7)** — G2 산출물 범위 내에서
   - `star-names-ko.csv`의 `needs_review` 정리(G2 결과로 교차 검증), 전통 이름을 검색 별칭·라벨 대안("직녀성(베가)")으로 노출하는 설정.
   - 28수·천상열차분야지도 오버레이는 **데이터(선 정의)가 라이선스와 함께 확보된 경우에만** 레이어로 추가(Stellarium `korean` skyculture의 개별 라이선스를 확인하고 `DATA-LICENSES.md`에 기록). 확보되지 않으면 보류 목록으로 넘기고 이유를 기록.

## 4. 기술 사양 메모

- 항목 JSON은 UTF-8, 줄바꿈은 `\n`, 마크다운 최소 서브셋(굵게·목록)만 허용하고 뷰어에서 안전하게 렌더(HTML 주입 금지).
- 카탈로그 대조는 T0의 팩을 읽어 수행(스크립트에서 바이너리 팩 파서 재사용).
- 우선순위 1 목록은 계절 무관 유명도 + 2026년 9~12월에 보이는 것을 섞는다(사용자가 당장 쓰기 위해).

## 5. UI/UX 지침

- 읽는 화면이므로 줄 간격·여백 넉넉히, 한 화면 한 섹션. 초보자 용어 ⓘ. 신화는 "이야기" 톤(문어체 과다 금지), 사실은 표.
- confidence가 medium 이하인 항목은 작은 "검토 중" 배지(신뢰를 과장하지 않기).
