## T9 — 클라우드 동기화 (D1)
- 2026-09-08: 사용자 요청으로 마당·아바타·천체별 사진·댓글을 후속 후보로 구체화했다. 단계/공개 조건은 `docs/COMMUNITY-AND-CUSTOMIZATION.md`, 판매 제안은 `docs/MONETIZATION-PLAN.md`(D-046)를 따른다. 로컬 꾸미기부터, 사진/댓글은 신고·차단·실제 운영 도구와 함께 도입한다. 아직 구현 착수/완료가 아니다.
- 재개 조건: 두 번째 기기 사용 또는 다른 사람과 공유 필요.
- 접근: Supabase(Auth + Postgres + Storage). 로컬 스키마의 `updatedAt/deletedAt` 기반 LWW(last-write-wins) 동기화, 블롭은 Storage. 오프라인 우선 유지. 익명 사용도 가능하게(로그인은 선택).
- 주의: 개인정보 안내 갱신, 백업 형식과의 호환.

## T10 — AI 대화(BYO API 키) (D2)
- 재개 조건: 정적 콘텐츠로 부족함을 느낄 때.
- 접근: 설정에서 사용자가 자기 API 키(Anthropic/OpenAI) 입력 → 기기에만 저장 → 상세 시트 "질문하기". 시스템 프롬프트에 현재 대상·시각·위치·장비·기록을 컨텍스트로 넣고, 답변에 "확인되지 않은 정보" 표시. 비용 안내.
- 주의: 키를 서버로 보내지 않음(브라우저에서 직접 호출; CORS 가능한 API만).
