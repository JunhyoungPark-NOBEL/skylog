## 1. 목표

"토성", "M13", "직녀성", "안드로메다"를 치면 즉시 찾고, 상세 시트에서 **지금 볼 수 있는지·언제 가장 좋은지**를 알 수 있으며, "하늘에서 보기"를 누르면 화면이 그쪽으로 날아가거나(수동) 화면 가장자리 화살표가 방향을 알려준다(AR). "오늘 밤" 탭은 위치·시각·날씨·달·계절·장비를 종합해 **맨눈/쌍안경/망원경별 추천 목록과 시간대별 관측 계획**을 보여준다.

## 2. 범위

- In: `features/search`, `features/object`(상세 바텀 시트), `features/tonight`, `astro/recommend.ts`, `services/weather.ts`, 위젯(박명·달·출몰), 화면 밖 화살표, "실제 하늘처럼" 모드, 유성우 달력·천문 현상.
- Out: 기록/북마크 저장(T4 — 시트의 버튼 자리만), 망원경 모드(T5 — 버튼 자리만), 스토리(T6 — 탭 자리만).

## 3. 요구사항

### MUST

1. **검색** (`features/search/`, `catalog/searchIndex.ts`)
   - MiniSearch(또는 Fuse.js) 인덱스: `search-index.v1.json`을 앱 시작 후 백그라운드 로드. 접두 검색 + 퍼지(오타 1글자) + 별칭 정규화(T0 규칙과 동일 함수 재사용). 한글·영문·기호(M31/NGC 224/α Lyr/Alpha Lyrae/알파 리라) 모두.
   - 결과 랭킹: 정확 일치 > 접두 > 퍼지; 같은 점수면 밝은 것·지금 지평선 위인 것 우선. 결과 행에 종류 아이콘, 이름(ko + en), 별자리, 등급, **지금 상태**(고도 °/지평선 아래/낮).
   - 최근 검색 10개, 카테고리 칩(행성·달 / 별 / 별자리 / 성단 / 성운 / 은하 / 메시에), 빈 검색어일 때 "지금 보이는 유명 천체" 제안.
   - 검색 입력은 300ms 디바운스, 결과 ≤ 50, 키보드 열림 시 레이아웃 안정.

2. **천체 상세 바텀 시트** (`features/object/ObjectSheet.tsx`) — 어디서든 `openObject(id)`
   - 헤더: 이름(ko/en/기호), 종류·별자리, ★/☆ 상태 자리(T4), 즐겨찾기.
   - **지금**: 고도·방위(방위는 "남동 132°"처럼 16방위 + 각도), 상태 배지(보임/지평선 아래/박명·낮/태양 근접), 거리(광년 or AU), 등급, 크기(′), 달과의 각거리.
   - **오늘**: 출·남중(최고 고도)·몰 시각(현지 시간), 관측 최적 시간대(고도 ≥ 30°인 구간 ∩ 어두운 시간), "가장 좋은 달"(연중 남중이 자정 근처인 달 계산).
   - **좌표**: J2000 RA/Dec(시분초·도분초), JNow, Alt/Az — 각각 복사 버튼(GoTo 마운트용).
   - **이 장비로**: 맨눈/쌍안경/망원경 판정(T0 `visibility.ts`·`optics.ts`; 장비 프로필은 T5 전까지 기본값: 쌍안경 10×50, 망원경 90mm f/5.5).
   - 버튼: `하늘에서 보기`, `망원경으로 찾기`(T5 전엔 비활성+툴팁), `★ 관측 기록`(T4 전엔 비활성), `☆ 관측 예정`(**여기서 구현**: T0가 만든 Dexie `bookmarks` 테이블에 토글 저장 — T4는 UI·통계를 확장), `스토리`(T6 전엔 비활성). 시트는 반쯤 열림/전체 열림 2단계, 스와이프로 닫기.
   - 별자리를 열면: 그 별자리의 주요 별·DSO 목록, 계절, 지금 위치.

3. **찾아가기** (`features/sky/TargetGuide.tsx`, `viewStore.target`)
   - 수동 모드: `flyTo(target)` 후 목표에 선택 마커, FOV는 대상 크기에 맞춰(행성 20°, DSO 30°, 별자리 전체가 들어가게).
   - AR 모드: 목표가 화면 밖이면 **가장자리 화살표**(목표 방향의 화면 경계 위치에 배치, 회전 각도 = 화면 중심→목표 벡터 각) + 남은 각거리("↗ 37°"). 화면 안에 들어오면 링 마커 + 각거리, 중앙 3° 안이면 색 변화 + 피드백(진동/소리). "목표 해제" 버튼.
   - 목표가 지평선 아래면 "n시간 뒤 떠오름" 안내와 "그때 알림"은 하지 않음(보류) — 대신 시간 슬라이더 바로가기.

4. **박명·태양·달 계산 & 위젯** (`astro/events.ts` 확장, `features/tonight/SkyStatusCard.tsx`)
   - 오늘/내일: 일몰, 시민·항해·천문박명 종료/시작(`SearchAltitude(Body.Sun, …, −6/−12/−18)`), 일출, 월출·월몰(`SearchRiseSet(Body.Moon, …)`), 달 위상 이름·조도(%)·달 나이, 달이 뜨는 시간대 → **"어두운 창(dark window)"** = 천문박명 끝 ~ 시작 중 달이 없는(또는 고도 < 10°) 구간을 계산·표시. "밤"의 정의는 현지 정오→정오(`nightKey`, 마스터 플랜 §6.3).
   - 위젯: 가로 타임라인(18:00~06:00)에 밤의 어둠 단계(그라데이션), 달 있음 구간, 구름 예보(있으면) 겹쳐 그림. 현재 시각 커서.

5. **날씨** (`services/weather.ts`, 온라인 시에만, 실패해도 앱은 정상)
   - Open-Meteo `/v1/forecast?latitude&longitude&hourly=cloud_cover,cloud_cover_low,cloud_cover_mid,cloud_cover_high,visibility,relative_humidity_2m,dew_point_2m,temperature_2m,wind_speed_10m,precipitation_probability&timezone=auto&forecast_days=2`(키 불필요, CORS 지원, **CC BY 4.0 — 카드에 "Weather data by Open-Meteo.com" 표기**). 1시간 캐시는 Dexie `cache` 테이블(T0 생성)에 만료 시각과 함께 저장.
   - 7Timer ASTRO `https://www.7timer.info/bin/api.pl?lon&lat&product=astro&output=json`(seeing 1~8, transparency 1~8, cloudcover 1~9, 3시간 간격). CORS 안 되면 **과감히 생략**하고 DECISIONS에 기록(프록시 서버 만들지 말 것).
   - 표시: 시간별 구름(저/중/고 세 줄 막대), 시상·투명도(있으면), 습도·이슬점(결로 경고: 이슬점과 기온 차 < 2°C), 바람. 관측 적합도 요약 한 줄("21시~01시 구름 10% 이하, 시상 보통").

6. **추천 엔진** (`astro/recommend.ts`, 순수 함수 + 테스트)
   - 후보 집합: 행성 7 + 달 + 고유명 별(mag ≤ 2.5) + 메시에 110 + 콜드웰 + 이름 있는 DSO + 유명 이중성 몇 개(알비레오, 미자르 등 큐레이션) + 별자리(계절 대표).
   - 관측 창: 사용자가 고른 시간대(기본: 천문박명 끝 ~ 01:00, 또는 "지금부터 2시간"). 10분 간격으로 alt/az 샘플링.
   - **관측지 하드 필터(C15)**: `Site.visibleAz`·`minAltDeg`가 설정되어 있으면 그 구간·고도 밖에 있는 시간은 "보이지 않음"으로 처리(창에서 제외). 설정이 없으면 전 하늘. 결과 카드에 "베란다 기준" 배지.
   - 대상별 지표: 최고 고도·시각, 고도 ≥ 30° 지속 시간, 달과의 최소 각거리, 방위(동/남/서), 가시성 판정(장비별: 한계등급·표면 밝기 근사 `mag + 2.5·log10(면적)`), 신선도(아직 기록 없음 → T4 이후 보너스), 계절 시그니처(큐레이션 표: 여름 대삼각형, 겨울 다이아몬드, 봄 은하 시즌 등), 특별 이벤트(충 근처 행성, 최대이각, 극대기 유성우).
   - 점수 = 가중합(가중치 상수는 파일 상단에 표로, 근거 주석). 구름 ≥ 70%인 시간은 창에서 제외. 결과를 **그룹**으로: "지금 당장", "맨눈으로", "쌍안경으로", "망원경으로", "곧 진다(서두르세요)", "올라오는 중". 각 항목에 이유 문구 자동 생성("남동 62°, 달과 80° 떨어짐, 22:40 최고").
   - "오늘 밤 계획": 시간순 정렬(각 대상의 최적 시각), 최대 12개, 대상 탭 → 상세 시트, "계획에 추가" → Dexie `bookmarks`(☆)에 저장(T4가 목록 UI를 확장).

7. **"오늘 밤" 탭** (`features/tonight/`)
   - 카드 순서: ① 하늘 상태(박명·달·날씨 타임라인) ② 오늘의 하이라이트(행성·특별 이벤트 1~3개) ③ 추천 그룹 ④ 이달의 천문 현상 ⑤ 유성우.
   - 시간대 선택(지금부터 2h / 저녁 / 심야 / 새벽 / 직접), 장비 선택(맨눈/쌍안경/망원경), 위치는 `locationStore`.

8. **천문 현상·유성우** (`astro/phenomena.ts`)
   - astronomy-engine으로 계산: 행성 충/합(`SearchRelativeLongitude`), 내행성 최대이각(`SearchMaxElongation`), 달 위상 4분기(`SearchMoonQuarter`), 월식·일식(`SearchLunarEclipse`/`SearchGlobalSolarEclipse` — 위치 기준 가시 여부는 `SearchLocalSolarEclipse`), 근지점 보름달. 이번 달 목록(날짜·설명·가시 여부).
   - 유성우: `meteors.v1.json` + 극대일 달 조도 계산 → "관측 조건" 등급.

9. **"실제 하늘처럼" 모드** (`features/sky/RealSkyToggle.tsx`)
   - 한계등급 = f(Bortle(관측지 설정 or 기본 7), 달 조도·고도, 박명 단계, 구름은 제외) → `uLimitingMag`로 렌더러에 공급. 토글 시 도시 하늘에서 별이 확 줄어드는 것이 보여야 한다.

## 4. 기술 사양 메모

- 출몰·최적 시간 계산은 대상당 ms 수준이어야 한다(추천 후보 ~400개 × 샘플 40개 = 16k 변환 → 회전행렬을 샘플 시각마다 1개 계산해 모든 대상에 적용, `Horizon()`을 대상마다 부르지 말 것). Web Worker로 옮기면 좋다(SHOULD).
- 16방위 변환, 시분초 포맷, 현지 시간 포맷 유틸은 `ui/format.ts`로 모으고 테스트.
- 화면 밖 화살표: 목표 씬 벡터를 카메라 공간으로 → 뒤쪽(z>0)이면 화면 중심 대칭으로 뒤집어 처리 → 화면 사각형과 교차하는 경계점에 배치.
- 표면 밝기 판정은 근사임을 UI에 "참고" 표기.
- Open-Meteo 응답은 `hourly.time` 배열이 현지 시간(`timezone=auto`)이므로 파싱 시 주의.

## 5. UI/UX 지침

- 검색은 하늘 화면에서 한 번의 탭(하단 탭 또는 상단 검색 바)으로. 결과 탭 → 시트 반 열림 + 하늘이 그 대상으로 이동(수동 모드).
- 상세 시트 정보는 "지금 → 오늘 → 좌표 → 장비" 순서, 숫자는 굵게·단위 작게. 초보자 용어에는 ⓘ 툴팁(고도·방위·등급·박명).
- "오늘 밤"은 카드형, 각 추천 항목은 한 줄 이유 + 최적 시각 + 방위 아이콘.
