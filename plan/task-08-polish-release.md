## 0. 세션 시작 절차

1. STATUS의 "알려진 이슈"와 사용자 피드백을 **이슈 목록**(`docs/RELEASE-v1.md`의 체크리스트)으로 모은다. 심각도(막힘/불편/미관) 분류 후 막힘 → 불편 순으로 처리.
2. 순서: 이슈 정리 → 온보딩·설정 완성 → i18n 누락 스캔 → 성능 → 오프라인/PWA 감사 → 접근성 → 에러 처리·로깅 → 문서·라이선스 화면 → 릴리스.

## 1. 목표

처음 설치한 사람이 **안내 없이** 하늘을 보고, 검색하고, 기록할 수 있다. 폰에서 빠르고(첫 표시 ≤ 2초, 하늘 ≥ 45fps), 오프라인에서 완전히 동작하며, 야간 모드·접근성·에러 처리가 빈틈없고, 데이터 라이선스 고지가 완비된 **v1.0** 태그와 배포 URL.

## 2. 요구사항

### MUST

1. **온보딩**(첫 실행 3~4장): ① 무엇을 하는 앱인지 ② 위치 권한(왜 필요한지) ③ 하늘 보기 제스처·AR 모드 소개 ④ 야간 모드·화면 밝기·암순응 팁. 건너뛰기 가능. 이후 "배우기" 탭의 첫 학습 경로 제안(T7).
2. **설정 화면 완성**: 테마(자동/다크/야간), 언어, 관측지, 장비, 표시 옵션(라벨 언어·별 채도·확대 표시·대기 효과), 센서(Provider·편각 보정·필터 강도·시뮬레이터), 데이터(백업/복원/삭제·용량·persist), 학습(퀴즈 켬/끔), 정보(버전·데이터 팩 버전·라이선스·출처·오픈소스 고지), 디버그(센서·데이터·성능 HUD).
3. **i18n**: 하드코딩 문자열 스캔 스크립트(`scripts/i18n-check.ts`: JSX 내 한글/영문 리터럴 검출) → 누락 0. `en.json` 완성(천체 이름은 카탈로그 en). 날짜·시간·숫자 로케일 포맷.
4. **성능**: 번들 분석(초기 JS gzip ≤ 500KB, 데이터 팩 지연 로드 확인), 코드 스플리팅(탭·망원경 모드·스케치·콘텐츠 뷰어 lazy), 렌더 루프 프로파일(정지 시 0 draw, 드래그 시 ≥ 55fps 데스크톱), 메모리 누수 점검(탭 전환 100회), 이미지·아이콘 최적화. 성능 HUD(fps·draw call·별 수)를 디버그 설정에.
5. **PWA·오프라인 감사**: 설치 가능(manifest·아이콘·스크린샷), 오프라인에서 모든 탭 동작(날씨 카드만 숨김), 업데이트 알림("새 버전 — 새로고침"), 캐시 버전 관리, iOS standalone 모드 상태 바·세이프 에어리어·홈 인디케이터 대응, 화면 회전·키보드·폰트 스케일(접근성 확대 200%) 대응.
6. **접근성**: 포커스 순서·라벨(aria)·대비(야간 모드 포함, WCAG AA 근접), 터치 타깃 ≥ 44px, 애니메이션 감소 설정 존중(`prefers-reduced-motion`), 스크린 리더로 주요 흐름 1회 점검(텍스트 대안).
7. **에러 처리·복원력**: React ErrorBoundary(탭 단위), 데이터 팩 로드 실패 시 재시도·안내, WebGL 미지원 안내(2D 폴백은 하지 않음 — 안내만), 센서 실패 안내, IndexedDB 실패 시 메모리 모드 경고, 전역 로그 링버퍼(디버그 화면에서 복사). 외부 수집 없음(프라이버시).
8. **실기기 QA 매트릭스**(사용자 협조): iOS Safari(최신), Android Chrome(최신), 태블릿 1종(가능하면), 데스크톱 Chrome/Firefox/Safari. `docs/TESTING.md`의 체크리스트를 **릴리스용 시나리오 12개**로 정리(설치→온보딩→AR→검색→찾아가기→기록→망원경 정렬→호핑→스토리→퀴즈→백업→오프라인). 결과 표를 `docs/RELEASE-v1.md`에 기록.
9. **문서·법적 고지**: README(스크린샷, 기능, 설치, 개발), `docs/DATA-LICENSES.md` 최종(파일 단위), 앱 내 라이선스 화면(HYG CC BY-SA 4.0, OpenNGC CC BY-SA 4.0, d3-celestial 코드 BSD-3 + 데이터 파일별 출처, NASA SVS PD, **Open-Meteo CC BY 4.0("Weather data by Open-Meteo.com")**, **7Timer 크레딧**(사용 시), astronomy-engine MIT, Three.js MIT, 콘텐츠 출처(위키백과 CC BY-SA 등), 프로젝트 라이선스 MIT/데이터 팩 CC BY-SA 4.0), 개인정보 안내(모든 데이터는 기기에만, 내보내기에 좌표 포함 경고), 태양 안전 문구.
10. **릴리스**: `CHANGELOG.md`, 버전 `1.0.0`, 태그 `v1.0.0`, 배포 URL 확인, STATUS에 "v1.0 릴리스" 기록, 보류 목록(`99-deferred-tasks.md`) 우선순위 재검토 제안.
