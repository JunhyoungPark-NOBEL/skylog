# Task 4 — 관측 기록 · ★ 북마크 · 특징 메모 · 스케치 · 통계 · 내보내기/가져오기

> 실행 전 읽기: `plan/00-master-plan.md` §6.3(스키마), `plan/STATUS.md`(T3 보고)
> 선행: T3. 예상 분량: 세션 1~2개.

## 0. 세션 시작 절차

1. STATUS 확인, 저장소 최신화, 테스트 통과. T0의 Dexie 스키마와 타입을 다시 읽는다(변경이 필요하면 마이그레이션 + DECISIONS).
2. 순서: DB 계층 → 기록 폼 → 하늘 ★ 오버레이 → 기록 탭(목록·달력·대상별) → 스케치 → 통계 → 내보내기/가져오기 → 추천 연동.

## 1. 목표

관측한 천체를 **★로 기록**(시각·장소·장비·조건 자동 채움 + 특징 태그·자유 메모·스케치·사진·평점)하고, 하늘 위에서 내가 본 천체가 ★로, 보려고 표시한 천체가 ☆로 보인다. 기록 탭에서 시간순·달력·대상별로 되돌아보고 통계(별자리·메시에 진행률)를 본다. 기록은 JSON/CSV로 내보내고 복원할 수 있다.

## 2. 범위

- In: `db/*`(Dexie 구현, 마이그레이션, export/import), `features/log/*`, ★/☆ 렌더 레이어(`render/MarkerLayer.ts`), 상세 시트 액션 연결, 추천 엔진에 `observedSet` 공급, 통계.
- Out: 클라우드 동기화(D1), 소셜 공유(D11). 학습 진행(T7)은 같은 DB를 쓰되 여기서는 테이블만.

## 3. 요구사항

### MUST

1. **DB 계층** (`db/database.ts`는 T0에서 v1으로 생성됨 — 여기서는 `db/repo/*.ts`, 마이그레이션, export/import)
   - 테이블(T0 v1): `observations`, `bookmarks`(T3에서 사용 중), `sites`(T2에서 사용 중), `telescopes`, `eyepieces`, `binoculars`, `blobs`(`{id, kind:'sketch'|'photo', mime, blob, width, height, createdAt}`), `progress`, `settings`, `cache`. 필요한 인덱스 추가는 v2 마이그레이션으로: `observations.objectId`, `observations.observedAt`, `observations.nightKey`, `bookmarks.objectId`.
   - 소프트 삭제(`deletedAt`), `updatedAt` 자동 갱신 훅, uuid v4, `nightKey`(현지 정오→정오 기준 'YYYY-MM-DD') 자동 계산. 마이그레이션 버전 관리(`db.version(n).stores(...)`), 기존 데이터 보존 테스트.
   - 리포지토리 API(순수 async 함수, 테스트는 `fake-indexeddb`): `addObservation`, `updateObservation`, `deleteObservation`, `listObservations({objectId?, from?, to?})`, `toggleBookmark`, `getObservedSet(): Set<ObjectId>`, `getBookmarkedSet()`, `stats()`.
   - 파생 상태를 `logStore`(zustand)에 캐시: `observedSet`, `bookmarkedSet`, 최근 기록. DB 변경 시 갱신(`liveQuery` 또는 이벤트).

2. **기록 폼** (`features/log/ObservationForm.tsx`) — 상세 시트의 `★ 관측 기록`, 하늘의 선택 마커, 기록 탭의 "+"에서 열림
   - **자동 채움**(수정 가능): 대상, 시각(지금)·`nightKey`, 관측지(현재), 대상의 alt/az, 달 조도·위상각(`moonPhaseDeg`)·각거리, 날씨(있으면 구름·기온·습도), 장비(마지막 사용), Bortle(관측지 설정).
   - 입력: 관측 방법(맨눈/쌍안경/망원경 + 접안렌즈·배율), 시상 1~5, 투명도 1~5, 평점 1~5(별), **특징 태그 칩**(카테고리별 프리셋: 색(붉은/푸른/노란/흰), 형태(원반/타원/나선팔 느낌/중심 밝음/가장자리 흐릿/길쭉함), 분해(별로 분해됨/보풀/점처럼), 이중성(분해됨/색 대비), 행성(고리/줄무늬/위성 n개/위상), 달(크레이터/터미네이터/바다), 난이도(쉬움/보통/어려움), 기법(주변시/필터 사용)), 자유 메모(멀티라인), 스케치(캔버스 열기), 사진(`<input type=file accept=image/* capture>` → 리사이즈 1600px → blob 저장), **결과 토글** `outcome: seen | notSeen`("시도했지만 못 봤음" → 회색 ★, 통계의 "시도"로 집계).
   - 저장 후 시트 헤더가 ★로 바뀌고, 하늘에 마커가 즉시 나타남. 같은 대상 여러 번 기록 가능(히스토리).

3. **★/☆ 하늘 오버레이** (`render/MarkerLayer.ts`)
   - 관측 완료 = 금색 ★(작은 스프라이트, 대상 옆 오프셋), 관측 예정(북마크) = 흰 ☆ 윤곽, 시도했으나 못 봄 = 회색 ★. FOV에 따라 크기 일정(픽셀 단위). 야간 모드에선 적색 계열.
   - 마커 탭 → 상세 시트(기록 탭이 열린 상태). 레이어 패널에 "내 기록 표시" 토글.

4. **기록 탭** (`features/log/LogTab.tsx`)
   - 보기 3종: **타임라인**(밤(`nightKey`)별 그룹 — 자정 넘은 기록도 같은 밤에 묶임, 카드에 대상·장비·평점·태그·썸네일), **달력**(월별 히트맵, `nightKey` 기준, 날짜 탭 → 그 밤의 기록), **대상별**(내가 본 천체 목록, 종류 필터, 최근순/이름순/횟수순).
   - 검색/필터: 대상명, 태그, 장비, 기간. 스와이프 삭제(실행 취소 5초).
   - 기록 상세: 모든 필드 + 스케치/사진 뷰어 + "이 대상 다시 보기(하늘로)" + 편집.
   - **관측 예정(☆) 목록**: 오늘 밤 추천에서 "계획에 추가"한 것 포함, 각 항목에 지금 상태와 최적 시각, 완료 시 기록 폼으로 연결.

5. **스케치 캔버스** (`features/log/SketchCanvas.tsx`)
   - 검은 원형 시야(접안렌즈 느낌; T5 이후엔 실제 FOV 원 표시) 안에 흰/회색 펜, 굵기 3단계, 지우개, 실행 취소, 부드럽게(포인터 이벤트, 압력 무시). 배경에 대상의 실제 별 배치를 **연하게 겹쳐 보기** 옵션(오프스크린 렌더 — T3 SHOULD의 파인더 차트 재사용, 없으면 생략). PNG blob 저장, 썸네일 생성.

6. **통계** (`features/log/StatsCard.tsx`)
   - 총 관측 수·대상 수·관측 밤 수(`nightKey` 고유값), 종류별 카운트, **별자리 88개 중 n개**(대상의 `con` 기준), **메시에 110 중 n개**, 콜드웰 진행률, **행성 7종** 체크(수·금·화·목·토·천·해) + 달·태양, 달 위상 8단계 수집(`moonPhaseDeg`로 판정), 연속 관측 스트릭(밤 기준), 가장 많이 본 대상, 월별 그래프(간단 막대). `outcome:'notSeen'`은 "시도"로 따로 집계. 야간 모드 대응.

7. **내보내기/가져오기** (`db/exportImport.ts`)
   - JSON(마스터 플랜 §6.3 형식, blobs는 base64 포함 옵션) 파일 다운로드(`Blob` + `a[download]`, iOS는 공유 시트로 열림 안내). CSV(관측만, UTF-8 BOM, 엑셀 호환). **개인정보 안내**: 내보내기 대화상자에 "기록에는 관측지 좌표(집 등)가 포함됩니다" 한 줄 + "좌표를 소수점 2자리로 반올림(≈1km)" 옵션(공유용).
   - 가져오기: 파일 선택 → 스키마 검증(버전·필수 필드) → 미리보기(n건, 충돌 정책: `updatedAt` 최신 우선/모두 추가) → 실행. 실패 시 원자적 롤백(트랜잭션).
   - "모든 데이터 삭제"(확인 2단계).

8. **추천·검색 연동**
   - `recommend()`에 `observedSet`·`bookmarkedSet` 전달: 미관측 보너스, 예정 목록 우선 표시. 검색 결과 행에 ★/☆ 표시.

### SHOULD

- 기록 폼에서 "지금 하늘에서 확인" 미니 차트(대상 위치).
- 기록에 **관측 세션** 개념(같은 밤·장소 묶음): 세션 노트(전체 컨디션, 장비 세팅), 세션 내 기록 순서. 스키마의 `sessionId?`를 사용(§6.3에 이미 있음).
- 사진 EXIF 촬영 시각으로 시각 자동 보정 제안.

### COULD

- 기록 카드 이미지 공유(캔버스 합성) — 개인용이라 낮은 우선순위.
- 음성 메모(장갑 낀 손) — MediaRecorder, 보류 가능.

## 4. 기술 사양 메모

- Dexie 4 `liveQuery`로 스토어 동기화. 대량 목록은 가상 스크롤(수백 건까지는 단순 렌더로 충분, 필요 시 `react-virtual`).
- 사진 리사이즈는 `createImageBitmap` + 캔버스, EXIF 방향 처리(`image-orientation: from-image` CSS 또는 수동).
- iOS PWA에서 IndexedDB는 **7일 미사용 시 삭제될 수 있음**(ITP) → 설정 화면에 경고 + "정기 백업" 권고 + 홈 화면 설치 시 완화된다는 안내. 자동 백업 리마인더(30일마다 배너).
- 저장 용량 표시(`navigator.storage.estimate()`), `persist()` 요청.

## 5. UI/UX 지침

- 야외·어둠·장갑: 기록 폼은 **칩 탭 위주**, 텍스트 입력은 마지막. 저장 버튼은 하단 고정, 큰 크기.
- ★는 금색(야간 모드에서는 밝은 적색), 인지하기 쉬운 크기. 하늘이 어지럽지 않게 FOV > 90°에서는 밝은 대상 마커만.
- 통계는 자랑보다 "다음에 볼 것"으로 연결(별자리 미완주 목록 → 검색).
