## 사실·원값·편집 제안의 구분

첨부 파일은 대상 ID와 수치의 원본이다. `raw-selected-values.json`의 **20행 × 12열 = 240개 셀**과 `inputs/` 원본을 보존했다. 수치의 원본과 과학적 타당성 검증을 혼동하지 않는다.

원자료에는 은하 M31의 거리가 `544`, M51이 `418`로 입력되어 있다. 해당 열의 이름은 `dist_ly`다. NASA 자료와 규모부터 다르므로 이 값들을 사실 설명으로 교육하지 않는다. M13·M3·M15까지 **5개 거리의 숫자 표시를 보류**하고 원값과 외부 대체 후보를 검토 파일에 분리했다. 외부 후보 역시 최신 정밀 카탈로그의 확정값으로 선언하지 않았다.

나머지 기존 거리 12개, 별 분광형 3개, 겉보기등급 20개, DSO 각크기 17개는 입력 문자열 또는 숫자를 보존했다. 빈 거리 3개는 비워 두고 facts에서 생략했다. **모든 `mag`의 측광 대역이 미확인이므로 V등급이라고 쓰지 않았다.** 크기는 원래 수치를 유지하면서 각분 기호로만 표기했다.

요약·이야기에서 물리적 설명과 관측 역사는 NASA·ESA·IAU·연구 기관·원논문 및 명시한 한국 문화 자료에 근거한다. 스토리의 조언·기록법은 편집자의 제안이다. 신화 분량을 채우려고 새로운 전승을 만들지 않았다. 한국 전통 항목은 M45의 좀생이별과 스피카의 제한된 좌각 대응만 넣었다.

`observing`의 **10×50 쌍안경·90mm 굴절 20~80배**, 도시 광해의 한계, 성공 기준은 대상 특성과 일반 관측 원칙에 근거한 보수적 기획이다. 실제 해당 장비로 관측한 결과가 아니다. `bestMonths`는 한국 중위도 저녁의 대표 계절 제안이며 매일 21~24시 고도 25°를 계산해 보증한 결과가 아니다. T7 실제 미션은 천체력으로 다시 선별한다.

사진과 접안 시야, 같은 화면과 실제 물리적 동반 관계, 성군과 현대 별자리, 전체 C14와 개별 NGC 성단을 구별했다. `hopFrom`은 모두 원래 카탈로그에 존재하지만 그 ID의 읽기 콘텐츠까지 모두 작성된 것은 아니다.

## 검증 결과

패키지 검사 **43개 중 43개 통과, 0개 실패**. 스키마·문자 수·중복 ID·첨부 셀 보존·후보값 미적용·출처 참조·누적/잔여 목록과 각거리 5개를 검사했다. 하나의 검사에 여러 항목을 묶은 경우는 `validation.json`에 상세 범위를 표시했다.

| 필드 | 실제 최소~최대 | G3 지정 |
|---|---:|---:|
| oneLiner | 24~29자 | 60자 이하 |
| summary | 263~285자 | 200~400자 |
| story | 344~377자 | 300~600자 |
| facts | 5~6개 | 5~8개 |

문자 수는 NFC 문자열의 유니코드 코드 포인트 기준이다. JSON 스키마는 기존 배치의 검증 스키마를 유지했다. `meta.generatedBy='gpt-5-pro'`는 요청 스키마와의 호환성 때문에 유지한 문자열이며 실제 실행 모델을 인증하는 값이 아니다.

재검증:

```sh
python -m pip install jsonschema
python validate.py
python validate.py --release
```

첫 실행은 구조가 같다면 종료코드 0을 반환한다. `--release`는 사람의 검토·실제 게시 승인이 없으므로 **의도적으로 종료코드 2**를 반환한다. 자동 구조 검사 통과를 콘텐츠 배포 승인으로 바꾸지 않는다. 이 검증 스크립트는 이 패키지에 대한 검사이며 실제 Claude T6 저장소의 검사기를 실행한 것이 아니다.

## 남은 일과 수행하지 않은 일

새 초안의 확신도는 medium 15개, 거리 격리로 low 5개다. 그렇다고 medium 항목이 자동 게시 승인된 것은 아니다. 거리 오류 후보의 원천 추적, 전체 등급 대역 확인, M42 분류·M5 키 매핑, 일부 전문 출처와 전통 이름 검토가 남았다. 입력 CSV에는 원천 카탈로그 URL·판본·epoch가 없어 그 provenance를 이번 작업만으로 복원하지 못했다.

실제 접안 관측, 앱 기능 검사, T6 검증·병합·커밋, 실제 콘텐츠 인덱스 게시, G5 미션/퀴즈 추가, 전천 skyPick 근접 검사는 수행하지 않았다. 웹 자료의 이미지·PDF·전체 연구 본문·전통 별자리 도형은 패키지에 포함하지 않았다. 출처별 재사용 조건 검토 없이 이 패키지 전체에 특정 외부 라이선스를 일괄 부여하지 않는다.
