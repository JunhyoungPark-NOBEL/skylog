## 실제 수행한 검사

`validation.json`의 상태는 **구조 검사 통과 + 편집 검토 필요**입니다. 자동 검사 오류는 0개입니다.

| 검사 | 결과 |
|---|---|
| JSON 재읽기, 지정 키·타입·enum, ID 순서·중복 | 통과 |
| oneLiner 길이 | 29–40자 / 상한 60자 |
| summary 길이 | 207–262자 / 허용 200–400자 |
| story 길이 | 322–371자 / 허용 300–600자 |
| facts 수 | 5–6개 / 허용 5–8개 |
| funFacts 수·길이 | 항목당 최대 3개, 각 80자 이하 |
| 별의 거리·등급·분광형·별자리 코드 | 11개 × 4필드 = 44건, 첨부값 보존 확인 |
| 한국어·영어 기본 제목 | 20개 모두 첨부 이름과 일치 |
| hopFrom | 모든 참조가 전체 첨부 121개 대상 안에 존재 |
| facts·story·koreanTradition 출처 | 각 출처가 해당 항목 sources에 포함 |
| 태양 안전 | 필수 문구 및 summary 첫 문장 확인 |
| 태양계의 고정 관측 월 | 9개 모두 bestMonths 생략, season=any |

문자 수는 공백과 문장부호를 포함한 유니코드 코드 포인트 수입니다. 외부 출처 URL은 56개이며 `source-registry.json`에 제목·URL·확인일을 모았습니다. 이 수치는 모든 URL의 자동 HTTP 정상 응답을 검사했다는 뜻이 아닙니다.

## 입력 보존과 외부 조사 구분

**첨부값:** 별의 거리·등급·분광형·별자리 코드는 원문을 유지했습니다. `A0m...`, `A0Vvar`, `F7:Ib-IIv SB` 등 기호를 단순한 표준형으로 몰래 교체하지 않았습니다. `M1: comp`처럼 문제가 있는 값도 값 자체는 남기고 눈에 띄는 검토 표시를 붙였습니다.

**외부 보완:** 태양계의 종류·태양으로부터 평균 거리·주기, 천체의 물리적 설명, 과학사·설화는 항목에 연결한 NASA·ESA·ESO·ALMA·학술 연구·한국 기관 자료를 근거로 새로 요약했습니다. 태양계 facts의 AU 거리는 별도 표시가 없는 한 **태양과의 평균 거리**이며 지구와의 현재 거리가 아닙니다. 임의의 실시간 위치나 밝기를 생성하지 않았습니다.

**관측 안내와 계절:** 북위 약 36°의 한국 관측자를 기준으로 카탈로그 좌표와 공식 관측 안내를 참고해 작성한 편집 안내입니다. `bestMonths`는 별을 저녁에 찾아보기 좋은 대략적인 월이지, 그 달 모든 시각의 가시성이나 기상·고도를 보장하는 값이 아닙니다. 계절 enum은 제공된 값을 그대로 사용했습니다. 태양·달·행성은 현재 시각·위치를 앱에서 계산해야 하므로 `season=any`, `bestMonths` 생략, `hopFrom=[]`로 두었습니다. 태양에는 안전상 일반적인 맨눈 스타 호핑 절차를 적용하지 않았습니다.

장비별 내용은 맨눈 / 10×50 / 90mm 20–80배를 위한 **보수적인 관측 기대치와 제안**입니다. 실제 장비로 수행한 관측 보고나 각 대상의 검출 한계 실측값이 아닙니다. 실제로 잘 보이는 세부는 광해·달빛·고도·대기 안정도·장비·숙련도에 따라 달라집니다. 고배율에서 별이 번져 보이는 것과 실제 항성 표면을 구별하도록 했습니다.

**이야기:** 직접 인용을 복제하지 않고 새로 요약했습니다. `cultures=기타`에는 근대·현대 과학사와 과학 관측 해설이 포함됩니다. 모든 story가 신화라는 뜻은 아닙니다. 천체와 관련된 신화를 찾지 못한 경우 임의의 전승을 만들어 넣지 않았습니다.

## 공개 전 꼭 검토할 사항

**카펠라(HIP24608)는 출시 차단 항목입니다.** 첨부 분광형과 외부 연구 설명이 충돌하므로 `confidence=low`로 두었습니다. T0 상위 카탈로그의 행 매핑·성분·출처를 확인하기 전 자동 게시하지 마세요. 참고: [Takeda 외, 카펠라 분광 분석](https://arxiv.org/html/1806.09036v1).

베텔게우스와 데네브의 거리는 외부 연구·소개 자료와 추정 차이가 있습니다. 첨부값을 보존했지만 정밀한 값이나 현재 합의된 값으로 인증한 것은 아닙니다. 변광성의 등급도 실시간 값이 아닙니다. 구체적인 항목은 `review-items.md`에 있습니다.

전통 명칭 6건은 **Stellarium 한국 전통 별자리 재구성의 HIP 대응**임을 본문에 명시했습니다. 역사적 원전 전체를 대조해 보편적 별칭으로 확정한 것이 아닙니다. 성군과 구성별을 일대일로 합치거나, 한글이 같은 천고(天庫)와 천고(天高)를 하나로 합치지 마세요. 원자료 전체를 복제하거나 그 재배포 조건을 새로 판정한 결과도 아닙니다. 앞선 G2의 원전·이용 조건 검토를 함께 참조하세요.

그 밖에 태양 안전 흐름, 아르크투루스 표기, 변광성 대표 등급 등도 검토 이유를 적었습니다. 검토 표시가 있는 항목은 10개이며 confidence는 high 10 / medium 9 / low 1개입니다. high도 첨부 숫자의 상위 원전을 전수 검증했다는 뜻은 아닙니다.

## 남은 자료의 한계와 메타데이터

첨부 CSV에는 원 카탈로그의 버전·필드별 출처·측정 불확실도·좌표 epoch·광도 측정 대역이 별도로 없습니다. `mag`는 G3 지시의 V등급 규칙에 따라 표시했지만 **CSV만으로 그 대역을 독립 확인하지는 못했습니다.** T0에서 상위 원자료와 연결해 확인해야 합니다. 검증 결과의 “원값 보존”과 “천문학적으로 정확함”을 혼동하지 마세요.

`meta.generatedBy`의 `gpt-5-pro`는 제공된 **G3 v1 스키마의 고정 리터럴을 호환 목적으로 유지한 것**입니다. 실제 실행 모델을 확인한 인증값으로 사용하면 안 됩니다. 이 메타데이터를 실행 모델 이력으로 사용하려면 Claude 측에서 스키마를 바꾸고 별도의 신뢰할 수 있는 실행 기록을 보존해야 합니다. `generatedAt`은 작성 기준일인 `2026-09-07`이며 관측 시각이나 카탈로그 측정 epoch가 아닙니다.
