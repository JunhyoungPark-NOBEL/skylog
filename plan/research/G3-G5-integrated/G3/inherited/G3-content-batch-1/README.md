두 표의 ID 집합과 우선순위는 일치한다. 태양계 9개는 원본 순서로 포함했다. 항성은 **대상 표의 priority 오름차순, 동순위에서는 원본 행 순서**로 정렬해 처음 11개를 선택했다. G3의 배치 구성 규칙을 적용한 것이므로 모든 종류를 한꺼번에 priority로 정렬한 결과와는 다르다.

한국어 제목은 이번 카탈로그의 문자열을 보존했다. 따라서 `아르크투루스`, `폴라리스`처럼 이전 G2에서 별도 표기가 있었더라도 조용히 이름을 바꾸지 않았다. 별칭이 확인된 경우에만 `title.alt` 또는 `koreanTradition`을 추가했다.

## 본문을 읽고 병합할 때

**카탈로그에서 가져온 값과 외부 조사로 보완한 사실을 구분했다.** 항성의 거리·등급·분광형·별자리 값은 첨부 CSV의 레코드를 출처로 남겼다. 이 로컬 출처에는 존재하지 않는 웹 주소를 만들지 않았다. 본문 `sources`의 `첨부 카탈로그 — 파일명 (id=...)`은 패키지의 `inputs/` 파일에서 재확인할 수 있다.

첨부의 `mag` 컬럼에는 광도계 대역과 측정 시점이 없다. **값은 그대로 보존했지만 V등급으로 확정하지 않았다.** 이 배치의 항성 11개 모두 해당 이유가 `meta.needsReview`에 있다. 숫자만 추출한 뒤 확인된 V등급으로 다시 표시하면 원래의 유보 정보가 사라진다.

카펠라의 `spect=M1: comp`는 밝은 두 구성원을 **G8 III + G0 III**로 다루는 연구 문헌과 차이가 있다. 원본 값과 외부 비교 값을 별도 fact로 두었고, 해당 항목은 `confidence: low`로 남겼다. 이는 원본을 자동 수정한 것이 아니라 **HIP 레코드의 성분·출처를 확인해야 한다는 검토 요청**이다. [Torres 외(2015), Capella revisited](https://arxiv.org/html/1505.07461v1)

베텔게우스의 498광년, 데네브의 1411.9광년, 폴라리스의 432.6광년 역시 첨부 값이다. 원출처의 추정법·성분·측정 시점·불확도를 확인하지 못한 상태에서 더 정밀한 확정 거리로 해석하지 않는다. 특히 데네브의 다른 거리 가정은 연구 문헌에서 비교되지만, 이 배치는 어느 값을 새 표준으로 채택하는 작업이 아니다. [Meilland 외, HD 62623 연구의 데네브 비교 논의](https://arxiv.org/html/0912.1954v1)

태양계 9개는 첨부에서 위치·등급이 `variable`, 거리 등의 칸은 비어 있다. 따라서 현재 위치나 관측 등급을 지어내지 않았다. 태양계의 추가 수치는 NASA 자료 등으로 보완했다. 행성의 AU 값은 **태양에서의 평균 거리**이고 지구에서의 현재 거리가 아니다. 달의 약 0.00257 AU는 NASA의 약 385,000km를 JPL의 AU 정의로 환산한 값이며, 출처와 환산 여부를 fact에 표시했다. [NASA Moon Facts](https://science.nasa.gov/moon/facts/) · [JPL Astrodynamic Parameters](https://ssd.jpl.nasa.gov/astro_par.html)

## 관측 안내의 해석

관측 안내는 **한국 중위도의 입문 관측**을 가정했다. `bestMonths`는 별을 저녁에 살펴보기 좋은 대략적인 달 목록이며, 매일 특정 시각·고도 조건을 계산한 결과가 아니다. 행성과 달은 계절명으로 위치를 고정하지 않고 앱의 실제 날짜·관측지 계산을 먼저 확인하도록 했다. 태양계 항목에는 고정된 `bestMonths`를 넣지 않았다.

행성의 `hopFrom`은 빈 배열이다. 움직이는 행성에 영구적인 기준 별을 붙여 놓으면 다른 날짜에 잘못된 길을 안내할 수 있기 때문이다. 실제 기준 별은 해당 날짜의 계산 결과에서 정해야 한다. 항성의 28개 `hopFrom` 참조는 모두 첨부 카탈로그의 실제 ID다. 다만 일부 기준 천체는 이번 20개 콘텐츠에는 없으므로, **카탈로그상 존재 여부와 설명 콘텐츠의 준비 여부를 UI에서 구분**해야 한다.

10×50 쌍안경과 90mm 굴절망원경·20~80배에 대한 문구는 공개 관측 자료를 토대로 보수적으로 작성한 **편집 안내**다. 해당 장비를 실제로 시험한 성능표가 아니며, 도시 광해·고도·대기 안정도·거치 상태에 따라 달라진다. `difficulty`는 주된 관측 목표를 기준으로 하며, 어려운 동반성 분리나 대기 무늬까지 성공해야 한다는 뜻이 아니다. [Astronomical League 내행성 관측 안내](https://www.astroleague.org/solar-system-observing-program-inner-solar-system/) · [외행성 관측 안내](https://www.astroleague.org/solar-system-observing-program-outer-solar-system/) · [NASA 달 관측 안내](https://science.nasa.gov/moon/viewing-tips/)

태양에는 요약 첫 문장과 별도 `safety` 경고를 넣었다. 수성·금성·태양 가까운 달에도 태양 근처 탐색의 위험을 알렸다. 이 경고는 관측 완료 여부나 앱 진행률보다 우선해 표시해야 한다. 필터는 장비의 태양을 향한 입구에 설치하는 적합한 제품이어야 하며, 일식 안경을 쓴 채 무필터 쌍안경·망원경을 사용하면 안 된다. [NASA Eclipse Viewing Safety](https://science.nasa.gov/eclipses/safety/)

## 이야기와 출처

태양의 삼족오, 달의 토끼·두꺼비 표현, 금성의 샛별·개밥바라기, 시리우스의 천랑성, 베가·알타이르의 칠석 전승, 폴라리스의 북극성 역할을 해당 근거가 지원하는 범위에서 다뤘다. 서로 다른 전통 성군과 현대의 단일 별 ID를 무조건 합치지 않았다. 신화가 확인되지 않은 항목에는 지어낸 신화 대신 관측·발견·연구의 이야기를 사용했다.

`story.cultures`의 `기타`에는 현대 천문학·관측 과학사도 포함한다. 이를 새로운 전통 신화의 문화권으로 읽지 않는다. 국립민속박물관의 두 동적 페이지는 검색 결과의 기관 설명에서 제한된 사실을 확인했으며, 전체 본문을 읽은 것으로 표시하지 않았다. 자세한 접근 한계는 `source-registry.json`에 있다.

본문은 원문을 길게 복제하지 않고 재서술했다. 출처의 이미지·도판 파일은 이 패키지에 포함하지 않았다. 링크가 있다는 이유만으로 출처의 이미지나 전체 데이터베이스를 자유롭게 재배포할 수 있다는 뜻은 아니다.

## 생성 메타데이터 주의

`meta.generatedBy`의 **`gpt-5-pro`는 요청된 v1 스키마의 고정 리터럴을 유지한 값**이다. 이 문자열은 이 세션의 실제 실행 모델을 검증하는 정보가 아니며, 모델 출처를 증명하는 값으로 사용해서는 안 된다. 실제 모델 식별이 필요한 프로젝트라면 배포 전에 스키마를 개정하거나 별도의 검증된 실행 메타데이터를 기록해야 한다. 임의의 추가 필드를 콘텐츠 본문에 끼워 넣지는 않았다.

## 수행한 검증과 남은 검증

`validation.json`에 **32개 자동 검사 모두 통과**한 결과를 기록했다. 여기에는 엄격한 필드·enum·타입·길이 검사, 20개 대상 및 순서, 원본 이름·항성 수치 보존, ID 참조, 출처 연결, 안전 경고의 존재, JSON 재읽기와 파일 해시가 포함된다. **이 통과는 모든 천문학적 사실이 자동으로 승인됐다는 뜻이 아니다.**

카탈로그 원출처의 V 대역·분광형 성분·거리 불확도 확인, 실제 앱의 validator 실행, 콘텐츠 화면 표시 검토, 현장 관측 검증은 수행하지 않았다. 저장소를 수정하거나 커밋하거나 앱에 게시하지 않았다. `confidence: low`인 카펠라는 검토 해결 전에 자동 배포하지 않는 것을 권장한다. 다른 항성의 검토 표시도 그대로 전달한다.

재검사: `jsonschema`가 설치된 Python 환경에서 이 폴더의 `python validate.py`를 실행한다. 경로를 인자로 전달해도 된다. 이 스크립트는 **배치 1용**이며, 실제 프로젝트의 T6 검증기를 대체하지 않는다.

## Claude T6 전달
