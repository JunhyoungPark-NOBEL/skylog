## 게시 전에 중요한 판단

**두베:** `F7V comp`를 그대로 보존했습니다. 대학 관측소 자료가 설명하는 밝은 황색 거성과 어떤 구성별을 가리키는지 불분명하므로 성분 해석을 보류하고 `low`로 두었습니다. 교정 후보는 `null`이며 자동 교체하지 않습니다.

**변광성:** 알골·미라의 첨부 등급은 오늘 밤의 밝기나 최대·최소·평균 등급으로 사용하지 않습니다. 관측 월과 미라의 극대 시기도 같은 개념이 아닙니다. 정밀 변광 알림을 새로 구현하거나 예측하지 않았습니다.

**저공 대상:** 북위 36.35°에서 첨부 적위로 계산한 카노푸스 최고 고도는 약 1.0°, 포말하우트는 약 24.0°입니다. 대기굴절·지형·좌표 epoch 영향을 제외한 계산이며, 두 대상 모두 이 모델에서 G5의 25° 이상 조건을 통과하지 못합니다. [guide-checks.json](guide-checks.json)에 계산식과 제한을 남겼습니다.

**별자리:** 비어 있던 거리·등급·분광형·크기는 지어내지 않았습니다. 대표 RA/Dec를 전체 영역의 위치나 모든 구성별의 고도로 간주하지 않습니다. 북두칠성=큰곰자리 전체, 포말하우트∈물고기자리, 큰 사각형의 네 별 모두∈페가수스자리 같은 혼동을 피했습니다.

**기존 보류 승계:** 누적 파일의 앞 40개는 입력과 객체 단위로 같습니다. 기존 카펠라의 분광형 문제, M31·M51·M13·M3·M15 등의 거리 보류를 해결한 것으로 표시하지 않았습니다.

## 근거와 제한

첨부 표의 값, 외부 자료에서 확인한 설명, 좌표에서 유도한 계산, 저자가 제안한 관측 방법을 구별했습니다. [source-ledger.json](source-ledger.json)은 항목별 근거 연결, [source-registry.json](source-registry.json)은 URL·자료명·접근 범위를 제공합니다. 일부 NOIRLab·AAVSO·기관 자료는 직접 페이지 접근이 제한되어 **검색 색인의 본문 발췌만** 확인했습니다. 발췌에 없는 신화 세부나 정밀 수치로 확장하지 않았고, 오류 가능성이 보인 문구는 사용하지 않았습니다. 외부 링크의 향후 접근성까지 보증하지 않습니다.

문화·역사 설명은 출처를 요약해 새로 작성했습니다. 전통 명칭의 정확한 적용은 첨부 G2의 범위를 따르며, 모든 시대·지역의 유일한 정답이라는 뜻은 아닙니다. 이미지·원문 페이지를 패키지에 복제하지 않았습니다. G2 입력 자료를 실제 제품에 재배포할 때에는 해당 자료의 원래 라이선스 검토가 별도로 필요합니다.

`meta.generatedBy: "gpt-5-pro"`는 요청된 구 스키마의 호환성 상수로 유지했습니다. 실제 실행 모델의 검증된 식별자나 인증을 뜻하지 않습니다.

## 오프라인 재검증

```bash
python -m pip install -r requirements.txt
python build_content.py
python validate.py
```

기본 명령의 종료 코드 0은 **초안 검사 통과**입니다. 다음 명령은 알려진 검토 사유 때문에 현재 종료 코드 2로 배포를 차단합니다.

```bash
python validate.py --release
```

이후 문서의 수량을 다시 만들려면 `python make_docs.py`를 실행하세요. 체크섬 목록은 패키징 시 생성한 스냅샷으로 파일 수정 후에는 갱신해야 합니다.

저장소 병합·커밋, 실제 T6 런타임 테스트, 실기기 관측, G5 미션·퀴즈 수정은 수행하지 않았습니다. `draft-content-index.json`은 전달용 초안 목차이지 저장소의 `content/v1/index.json`이 아닙니다.
