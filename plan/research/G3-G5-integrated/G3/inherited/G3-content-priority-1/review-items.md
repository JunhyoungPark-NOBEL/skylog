## 2. 원본 필드의 의미 확인

**M42:** `Cl+N (openCluster)`의 복합 표기를 보존했다. NASA가 설명하는 M42는 별 탄생 성운이며 중심에 젊은 별무리가 있다. G5가 parenthetical 문자열만 읽어 산개성단 정답으로 처리하지 않도록 앱 category를 검토한다. 성운을 봤다고 별 네 개를 모두 분리했다고 기록하지 않는다.

**M5:** 입력 `Se1`은 표준 IAU 3글자 코드가 아니다. 문장과 사실표에서는 G2의 뱀자리(`Ser`)와 명시적으로 대응했지만 입력을 수정하지 않았다. 실제 데이터 키 정규화는 T0b에서 승인한다. 거리 28636광년·등급 5.95도 NASA 소개의 약 25000광년·6.7등급과 차이가 있어 정밀 비교 문제에서 제외한다.

**20개 전체 등급:** `mag`의 V 대역 여부, 개별 성분인지 합성광인지, DSO 적분 영역·카탈로그 판본이 없다. 각 값의 원문은 남겼으나 V등급·정밀 밝기 순서 문제에는 사용하지 않는다.

**DSO 17개 각크기:** 수치를 보존하고 각분 단위로만 표시했다. 원자료의 영역 정의가 미확인이므로 실제로 보일 시야원의 지름으로 바로 사용하지 않는다. M51은 주 은하/쌍의 범위, C14는 두 성단 합계/개별의 범위를 특히 구분한다.

**항성 3개 분광형:** `K3II+...`, `B1V`, `B9p`를 원문 그대로 보존했다. 생략 기호를 임의의 동반성 분류로 풀어 쓰지 않았다. 스피카는 소형 망원경으로 분광쌍성의 두 별을 직접 분리하는 목표가 아니다. 알비레오의 넓은 A/B 쌍이 중력적으로 결합됐다고 확정하지 않는다.

## 3. 전통 명칭과 열람 한계

M45의 좀생이보기는 문화적 풍속이다. 농사 결과를 과학적으로 예측하는 법이나 특정 한 구성별의 독점 이름으로 가르치지 않는다. 한국민족문화대백과사전 출처 표기를 유지한다.

스피카의 좌각 대응은 Stellarium `korean`의 특정 공개 재구성에 근거한다. 모든 시대의 한국 문헌에 대한 결론으로 일반화하지 않는다. 전통 데이터셋을 더 복제·병합하는 경우 출처와 재사용 조건을 별도로 확인한다.

M37의 NOIRLab 페이지와 Werner 외 연구, 페르세우스 NOIRLab 페이지, 알비레오 Jack 외 논문은 직접 열기 제한으로 검색 색인에 공개된 범위만 사용했다. `source-registry.json`에서 각 access 필드를 확인한다. M37의 백색왜성·성운 관련 연구가 있다는 설명을 넘는 자세한 수치는 넣지 않았다. 연구 존재 설명도 게시 편집 시 원문을 다시 확인하는 것이 좋다.

## 4. 관측과 참조

문장에 있는 천구의 북/동/서/남은 화면의 위/오른쪽/왼쪽/아래가 아니다. 성단을 찾는 기준 별의 카탈로그 존재는 확인했지만 모든 기준 별의 설명 콘텐츠가 게시된 것은 아니다. `guide-checks.json`의 미작성 읽기 참조를 확인하고, 읽기 카드가 없다고 하늘에서 기준 별을 없애지는 않는다.

10×50·90mm 안내는 실측 성능표가 아니다. 한국 중위도의 `bestMonths`도 날짜별 기상·고도·달빛 판정기가 아니다. T7 미션의 고도 25° 및 21~24시 조건은 실제 앱 천체력으로 다시 검사한다. NGC869·NGC884는 두 개의 개별 ID이지만, 하나의 맨눈 얼룩을 봤다는 이벤트로 관측 둘과 C14 배지를 동시에 자동 부여하지 않는다.
