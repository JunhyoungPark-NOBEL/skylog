로그인 메일을 눌러도 앱에 로그인되지 않아요

로그인을 시작한 앱으로 돌아와 ‘로그인이 안 되나요?’를 여세요. 메일의 확인 링크를 길게 눌러 복사한 다음 해당 화면에 붙여넣을 수 있습니다. 만료된 링크는 새 메일로 다시 시작하세요. 로그인 링크는 다른 사람에게 보내지 마세요.

온라인 계정과 데이터 삭제는 웹에서도 시작할 수 있습니다. 계정 삭제와 기기 내 관측 기록 삭제는 별개입니다.

별길 가이드에서 화살표가 안 보여요

별길 가이드에서 센서를 켜면 나침반을 이용해 목표 방향을 안내합니다. 더 정밀한 안내가 필요하면 휴대폰 윗부분을 경통과 나란히 고정하고 밝은 별 정렬을 선택하세요. 폰을 다시 장착하거나 앱이 백그라운드로 갔다면 정렬 상태를 확인하세요. 센서가 없는 기기에서는 차트와 스타호핑을 이용할 수 있어요. 카메라로 별을 자동 인식하는 방식은 아니에요.

웹에서 쓰던 기록을 앱으로 옮기려면

PWA의 설정 → 백업·복원 → JSON 내보내기로 파일을 저장하세요. 스토어 앱의 같은 화면에서 파일을 가져온 후 기록 수와 사진을 확인하세요. 확인 전에는 원래 기록을 삭제하지 마세요.

스타호핑 코스

배우기 → 코스에서 대표 스타호핑 코스를 고르세요. 실제 하늘에서 각 이정표를 확인하고 마지막 완료 버튼을 누르세요. 코스로 돌아와 관측 기록을 저장하면 두 단계가 모두 완료돼요. 시뮬레이터 연습은 업적에 반영하지 않아요.

Help in English

Operator: 박준형 (Junhyoung Park), Skyard. Support and privacy requests: tony030214@gmail.com.

If an email link opens another browser, return to the original app and open the sign-in recovery help. You can paste the email’s original confirmation link there. Request a new email if the link has expired. Never share authentication links with others.

Account and data deletion is also available from the web account screen. Online account deletion and local device data deletion are separate actions.

Turn on sensors in Starpath to start compass guidance. For finer pointing, mount the phone parallel to the telescope tube and optionally align to a bright star. Check alignment after remounting or returning from the background. Devices without motion sensors can use charts and star-hopping. This is compass and optionally aligned sensor guidance, not automatic camera star recognition.

To transfer records, export a JSON backup from the PWA and import it in the store app’s Backup and restore screen. Verify records and images before deleting the originals. In Learn → Courses, follow a star-hopping course in the real sky, confirm its legs, then save an observation. Simulated practice does not earn field achievements.
